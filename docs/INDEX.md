# Индекс документации

Карта документов репозитория: что читать первым и что сверяет гейты.
Числа и факты — только из `eval/facts/facts.v1.json` и `METRICS.md`.

## Человеку

| Документ | О чём |
|---|---|
| `README.md` | установка, использование, границы честности, источники |
| `README.en.md` | вход для не-русских читателей (продукт остаётся русскоязычным) |
| `RELEASE.md` | регламент выпусков: SemVer-нарезка, кадэнс, цикл, запреты |
| `METRICS.md` | фактические снимки проекта (звёзды, загрузки, внешние issue/PR) и регламент обновления |
| `CHANGELOG.md` | журнал версий (до 3.10.0 — в `docs/CHANGELOG-archive.md`) |
| `GOVERNANCE.md` | роли, подписи тегов, правила автономных коммитов (98 строк, заморожен гейтом) |
| `CONTRIBUTING.md` | как предлагать правки (без приглашений и обещаний сроков) |
| `SECURITY.md` / `SECURITY.en.md` | модель угроз и порядок сообщений |
| `PRIVACY_POLICY.md` | что проект не собирает |
| `CODE_OF_CONDUCT.md` | нормы общения |
| `ERRATA.md` | датированные отзывы чисел и интерпретаций |

## Агенту и машине

| Документ | О чём |
|---|---|
| `llms.txt` | машинный вход: маршрутизатор задач, контракт, идентичность, обновление |
| `SKILL.md` | инструкция агента (бюджет ≤4500 токенов, гейт I.18) |
| `contract.v1.json` | машинный контракт: инструменты, схемы вывода, коды, when_not, prohibited_uses |
| `identity.v1.json` | устойчивая идентичность продукта (сверяется `scripts/check_identity.py`) |
| `markers.v1.json` | реестр маркеров с доказательствами и статусами |
| `eval/facts/facts.v1.json` | реестр публичных чисел (единственный источник) |
| `AGENTS.md` | карта репозитория для агентов-редакторов |

## Гейты-сверки состава документов

- `scripts/check_docs.py` (I.17 счётчики, I.18 бюджеты строк/символов);
- `scripts/check_bundle_sync.py` (SKILL/references в двух копиях побайтово);
- `scripts/check_pages_router.py` (состав Pages и живые пути);
- `scripts/check_identity.py` (identity.v1.json против носителей);
- `scripts/check_facts.py` (токены витрины против реестра, strict-режим).
