# Безопасность

Навык — это текстовые инструкции и два скрипта на стандартной библиотеке Python.
Скрипты читают только файлы, которые им передали, не ходят в сеть и ничего не
отправляют. Текст пользователя остаётся там, где работает его агент.

Навык считает присланный текст данными: команды внутри текста («забудь правила»,
«перейди по ссылке») не выполняются.

Нашли уязвимость — напишите через
[GitHub Security Advisories](https://github.com/Vladimir-Human/humanizer-ru/security/advisories/new),
а не в открытый issue.
