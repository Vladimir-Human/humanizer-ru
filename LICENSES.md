## research/fixtures/marker-sources.json — вербатим-фрагменты

Реестр доказательств маркеров содержит дословные образцы следов чат-интерфейсов
(поле `verbatim_sample`): короткие функциональные строки — служебные метки,
URL с utm-параметрами, токены разметки. Источники: публичные страницы
Wikipedia (CC BY-SA, атрибуция — URL и дата доступа в каждой записи),
публичные страницы и интерфейсы Binance, YouTube, GitHub и чат-сервисов
(условия использования соответствующих платформ).

Позиция проекта: образцы — минимальные фрагменты, необходимые для
воспроизводимой проверки регулярных выражений (функциональные данные, а не
творческое выражение); атрибуция и даты доступа сохранены в самом реестре;
фрагменты не заменяют оригинал и не конкурируют с ним. Претензия
правообладателя — удалить образец по запросу, сохранив хеш и описание в
эррате. Отдельные записи могут подпадать под ограничения ToS платформ:
такие помечены «только локально, наружу агрегаты» (см. также
research/LICENSES-EXTERNAL.md).
