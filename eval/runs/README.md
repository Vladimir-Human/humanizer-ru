# Парные прогоны

Здесь пусто, и это честное состояние дел: ни одного реального парного прогона
ещё не собрано. Инструмент готов, чисел нет.

Почему каталог всё равно есть: `eval/HOW-TO-RUN.md` ссылается на этот путь,
и читатель инструкции не должен упираться в отсутствующий каталог.

## Как сюда попадают данные

Один прогон — один каталог вида `2026-07-25-baseline/` со структурой:

```
manifest.json
source/<id>.txt
without/<id>.txt
with/<id>.txt
```

Полный протокол и границы метрик — в [../HOW-TO-RUN.md](../HOW-TO-RUN.md).

## Чего здесь не должно быть

Примеров «для демонстрации». Сочинённый прогон, лежащий рядом с настоящими,
рано или поздно попадёт в отчёт как настоящий. Поле `provenance` в манифесте
заполняется без украшений.
