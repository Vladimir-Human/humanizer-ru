## Прогон 2026-07-26-baseline

Первичное судейство выполняла одиночная языковая модель (claude-fable-5);
2026-08-07 её вердикты заменены панелью из трёх слепых LLM-судей
(файл `2026-07-26-baseline-verdicts-panel-2026-08-07.json`) — итоговые
числа ниже и в results-JSON именно панельные. Обе ветки выполнены
сабагентами: `without` — без скилла, `with` — читающий `SKILL.md`
и справочники. Промпт дословно одинаковый для ветвей, температура среды
по умолчанию и явно не задавалась. Ключ соответствия лежал вне каталога
пакета, судья видел только обезличенные пары.

Корпус: 6 пар — 4 захваченных вывода русских моделей (2 GigaChat, 2 Алисы) и 2
человеческих контроля (фрагмент статьи Википедии и текст, написанный в проекте
для проверки ложных срабатываний). Доля контролей — треть.

| Метрика | Со скиллом | Без скилла |
|---|---|---|
| Ложные правки в человеческих текстах | 0 | 0 |
| Правок без дописанных фактов | 100% | 100% |
| Читаемость по вердиктам судьи | 0 | 0 (ничьих 6) |
| Потеря смысла | 0 | 0 |
| Изменение длины | −12,1% | −14,2% |
| Снятие regex-маркеров | нет данных | нет данных |

**Что показал замер.** Достигнута единственная заранее объявленная цель: ноль
ложных правок в человеческих контролях. Со скиллом оба контрольных файла
совпали с источником побайтово. Дописанных фактов нет ни в одной ветке.

**Что замер не показал.** Преимущества по читаемости на этом корпусе нет:
все шесть пар — ничьи по вердиктам панели (в архиве
`eval/results/2026-07-26-baseline.json`; ранее в этом README ошибочно
указывалось «2 против 1 при трёх ничьих»). Метрика
снятия маркеров не посчиталась вовсе: в выводах GigaChat и Алисы нет тех
regex-артефактов, на которые заточены выражения (метки цитирования OpenAI,
карточки Grok, редиректы Gemini). Это ограничение корпуса, а не результат
скилла, и оно же — главный вывод прогона: чтобы мерить снятие маркеров, нужен
корпус выводов тех моделей, которые эти маркеры оставляют.

Отчёт целиком: `eval/results/2026-07-26-baseline.json`.

Почему каталог существовал раньше пустым: `eval/HOW-TO-RUN.md` ссылается на
этот путь, и читатель инструкции не должен упираться в отсутствующий каталог.

## Как сюда попадают данные

Один прогон — один каталог вида `2026-07-26-baseline/` со структурой:

```
manifest.json
source/<id>.txt
without/<id>.txt
with/<id>.txt
```

Полный протокол и границы метрик — в [../HOW-TO-RUN.md](../HOW-TO-RUN.md).

## Чего здесь не должно быть

Примеров «для демонстрации». Сочинённый прогон, лежащий рядом с настоящими,
рано или поздно попадёт в отчёт как настоящий. Поле `provenance` в манифесте
заполняется без украшений.
