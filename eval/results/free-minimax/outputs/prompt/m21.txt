## Установка и быстрый старт

`rus-doc-anonymizer` — открытая Python-библиотека для обезличивания персональных данных в документах форматов `.docx` и `.pdf`.

- Репозиторий: [github.com/sec-lab-ru/rus-doc-anonymizer](https://github.com/sec-lab-ru/rus-doc-anonymizer)
- Текущая версия: 1.4.0
- Дата релиза: 10 ноября 2026 года
- Мейнтейнер проекта: Алексей Петрович Круглов

---

### 1. Требования к окружению

Чтобы поставить и запустить `rus-doc-anonymizer` 1.4.0, нужны такие условия:

- **Python 3.11 или выше.** Python 3.10 и более старые версии не поддерживаются.
- **Минимум 4 ГБ оперативной памяти.**
- Входные документы — `.docx` и `.pdf`.
- **Для распознавания сканов и картинок внутри PDF нужен установленный в системе Tesseract OCR версии не ниже 5.3.** Если Tesseract нет или его версия ниже 5.3, сканы могут распознаваться неправильно или не обработаются вовсе.

> Примерная скорость: обработка 100 страниц занимает примерно **3,5 секунды** на обычном офисном процессоре.

---

### 2. Установка библиотеки

Лучше ставить пакет в отдельное виртуальное окружение.

#### Linux / macOS

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install rus-doc-anonymizer==1.4.0
```

#### Windows PowerShell

```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install rus-doc-anonymizer==1.4.0
```

После установки проверьте, что попался Python нужной версии:

```bash
python --version
```

В выводе должно быть 3.11 или выше.

---

### 3. Установка и проверка Tesseract OCR

Если нужно работать с отсканированными PDF или с картинками, вшитыми в PDF, сначала убедитесь, что в системе есть Tesseract OCR версии **5.3 или новее**.

#### Проверка установленного Tesseract

```bash
tesseract --version
```

В выводе должна быть версия не ниже 5.3, например:

```text
tesseract 5.3.1
```

#### Установка Tesseract

##### Debian / Ubuntu

```bash
sudo apt update
sudo apt install tesseract-ocr
```

После установки проверьте версию. Если в репозитории дистрибутива лежит более старая версия, ставьте Tesseract из официального источника или берите актуальную версию пакета другим способом.

##### macOS

```bash
brew install tesseract
```

##### Windows

Лучше поставить Tesseract через установщик или менеджер пакетов. Например:

```powershell
choco install tesseract
```

Потом добавьте путь к исполняемому файлу `tesseract` в переменную окружения `PATH` и проверьте, что он доступен:

```powershell
tesseract --version
```

### 4. Быстрый старт

Минимальный пример обезличивания документа:

#### Обработка DOCX

```python
from rus_doc_anonymizer import anonymize_file

anonymize_file(
    input_path="contract.docx",
    output_path="contract_anonymized.docx",
)
```

#### Обработка текстового PDF

```python
from rus_doc_anonymizer import anonymize_file

anonymize_file(
    input_path="report.pdf",
    output_path="report_anonymized.pdf",
)
```

#### Обработка отсканированного PDF

```python
from rus_doc_anonymizer import anonymize_file

anonymize_file(
    input_path="scan.pdf",
    output_path="scan_anonymized.pdf",
)
```

> **Важно:** чтобы текст в отсканированных PDF и в картинках распознавался, в системе должен быть Tesseract OCR версии не ниже 5.3.

### 5. Проверка работоспособности

После установки можно выполнить короткий тест:

```python
from rus_doc_anonymizer import __version__

print(__version__)
```

Ожидаемый вывод:

```text
1.4.0
```

Если библиотека встала без ошибок, переходите к обработке документов.
