## Установка и быстрый старт

Открытая Python-библиотека **`rus-doc-anonymizer`** для обезличивания персональных данных в документах форматов **`.docx`** и **`.pdf`**.

- Репозиторий: [github.com/sec-lab-ru/rus-doc-anonymizer](https://github.com/sec-lab-ru/rus-doc-anonymizer)
- Текущая версия: **1.4.0**
- Дата релиза: **10 ноября 2026 года**
- Мейнтейнер проекта: **Алексей Петрович Круглов**

---

### 1. Требования к окружению

Для установки и работы `rus-doc-anonymizer` 1.4.0 соблюдайте эти требования:

- **Строго Python 3.11 или выше.**  
  Python 3.10 и более старые версии не поддерживаются.
- **Минимум 4 ГБ оперативной памяти.**
- Форматы входных документов:
  - `.docx`
  - `.pdf`
- **Для распознавания сканов и изображений внутри PDF нужен установленный в системе пакет Tesseract OCR версии не ниже 5.3.**  
  Если Tesseract отсутствует или его версия ниже 5.3, обработка отсканированных документов может работать некорректно или не запускаться вовсе.

> **Ориентировочная производительность:** обработка документа на 100 страниц занимает примерно **3,5 секунды** на обычном офисном процессоре.

---

### 2. Установка библиотеки

Лучше поставить пакет в изолированное виртуальное окружение.

#### Linux / macOS

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install rus-doc-anonymizer==1.4.0
```

#### Windows PowerShell

```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install rus-doc-anonymizer==1.4.0
```

После установки проверьте, что используется поддерживаемая версия Python:

```bash
python --version
```

В выводе должна быть версия **3.11 или выше.**

---

### 3. Установка и проверка Tesseract OCR

Если нужна обработка отсканированных PDF-документов или изображений в PDF, заранее проверьте, что в системе есть Tesseract OCR версии **5.3 или новее.**

#### Проверка установленного Tesseract

```bash
tesseract --version
```

В выводе должна быть версия не ниже 5.3, например:

```text
tesseract 5.3.1
```

#### Установка Tesseract

##### Debian / Ubuntu

```bash
sudo apt update
sudo apt install tesseract-ocr
```

После установки проверьте версию. Если в репозитории дистрибутива предлагается более старая версия, установите Tesseract из официального источника или используйте другой способ получения актуальной версии пакета.

##### macOS

```bash
brew install tesseract
```

##### Windows

Можно использовать установщик или менеджер пакетов, доступный для Tesseract, например:

```powershell
choco install tesseract
```

Затем добавьте путь к исполняемому файлу `tesseract` в переменную окружения `PATH` и проверьте, что он доступен:

```powershell
tesseract --version
```

---

### 4. Быстрый старт

Минимальный пример использования библиотеки для обезличивания документов.

#### Обработка DOCX

```python
from rus_doc_anonymizer import anonymize_file

anonymize_file(
    input_path="contract.docx",
    output_path="contract_anonymized.docx",
)
```

#### Обработка текстового PDF

```python
from rus_doc_anonymizer import anonymize_file

anonymize_file(
    input_path="report.pdf",
    output_path="report_anonymized.pdf",
)
```

#### Обработка отсканированного PDF

```python
from rus_doc_anonymizer import anonymize_file

anonymize_file(
    input_path="scan.pdf",
    output_path="scan_anonymized.pdf",
)
```

> **Важно:** чтобы текст в отсканированных PDF и изображениях распознавался, в системе должен быть Tesseract OCR версии не ниже 5.3.

---

### 5. Проверка работоспособности

После установки выполните короткий тест:

from rus_doc_anonymizer import __version__

Ожидаемый вывод:

```text

```

Если библиотека установлена корректно, переходите к обработке документов.
