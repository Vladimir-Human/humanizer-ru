# csvtidy

Утилита командной строки для очистки CSV-файлов. Удаляет пустые строки и дубликаты, порядок столбцов не трогает.

## Установка

```bash
pip install csvtidy
```

Нужен Python 3.10 или новее.

## Возможности

- удаляет полностью пустые строки
- удаляет дубликаты (совпадают все значения в строке)
- с флагом `--dry-run` показывает статистику и ничего не записывает

## Использование

```bash
csvtidy input.csv [output.csv]
```

Если выходной файл не указан, результат перезапишет исходный.

Очистить файл и сохранить результат в новый:
```bash
csvtidy data.csv data_clean.csv
```

Очистить файл на месте:
```bash
csvtidy data.csv
```

Посмотреть, сколько строк удалится, не меняя файл:
```bash
csvtidy --dry-run data.csv
```

Вывод `--dry-run`:
```
Будет обработано строк: 15 432
Пустых строк для удаления: 12
Дубликатов для удаления: 340
Итого останется строк: 15 080
Файл не изменён (режим --dry-run)
```

## Ограничения

- Файлы больше 2 ГБ пока не поддерживаются.
- Кодировка должна быть UTF-8.
