# csvtidy

Утилита командной строки, которая быстро чистит CSV-файлы: удаляет пустые строки и дубликаты. **Порядок столбцов при этом остаётся прежним**: колонки не сортируются и не переставляются.

## Установка

```bash
pip install csvtidy
```

## Требования

- **Python 3.10** или новее

## Возможности

- Удаляет полностью пустые строки
- Удаляет дубликаты: строки, у которых совпадают все значения
- Не трогает порядок столбцов и структуру файла
- Режим предпросмотра (`--dry-run`) показывает статистику изменений, но файл не записывает

## Использование

### Базовый синтаксис

```bash
csvtidy input.csv [output.csv]
```

Если выходной файл не указан, результат записывается поверх исходного.

### Примеры

Сохранить очищенный файл под новым именем:
```bash
csvtidy data.csv data_clean.csv
```

Очистить файл «на месте» (in-place):
```bash
csvtidy data.csv
```

Узнать, сколько строк удалится, не меняя файл:
```bash
csvtidy --dry-run data.csv
```

Пример вывода `--dry-run`:
```
Будет обработано строк: 15 432
Пустых строк для удаления: 12
Дубликатов для удаления: 340
Итого останется строк: 15 080
Файл не изменён (режим --dry-run)
```

## Ограничения

- **Размер файла**: файлы больше **2 ГБ** пока не поддерживаются
- **Порядок столбцов**: утилита не меняет ни порядок, ни количество столбцов, структура CSV остаётся такой же, как в исходном файле
- **Кодировка**: предполагается UTF-8 (стандартная для современных CSV)
