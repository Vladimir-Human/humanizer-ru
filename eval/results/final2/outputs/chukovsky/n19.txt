# csvtidy

Утилита командной строки для быстрой очистки CSV-файлов. Убирает пустые строки и дубликаты, а порядок столбцов не трогает.

## Установка

```bash
pip install csvtidy
```

## Требования

- Python 3.10 или новее

## Возможности

- Удаляет полностью пустые строки.
- Удаляет дубликаты: строки, у которых совпадают все значения.
- Оставляет столбцы на своих местах: не сортирует и не переставляет их.
- Умеет предпросмотр (`--dry-run`): показывает, сколько строк уйдёт, но файл не записывает.

## Использование

```bash
csvtidy input.csv [output.csv]
```

Если выходной файл не указан, результат записывается поверх исходного.

### Примеры

Очистить файл и сохранить результат в новый:
```bash
csvtidy data.csv data_clean.csv
```

Очистить файл на месте:
```bash
csvtidy data.csv
```

Посмотреть, сколько строк будет удалено, не меняя файл:
```bash
csvtidy --dry-run data.csv
```

Так выглядит вывод `--dry-run`:
```
Будет обработано строк: 15 432
Пустых строк для удаления: 12
Дубликатов для удаления: 340
Итого останется строк: 15 080
Файл не изменён (режим --dry-run)
```

## Ограничения

- **Размер файла.** Файлы больше 2 ГБ пока не поддерживаются.
- **Кодировка.** Утилита ожидает UTF-8, как в большинстве современных CSV.
