# csvtidy

Утилита командной строки для быстрой очистки CSV-файлов. Удаляет пустые строки и дубликаты, а порядок столбцов оставляет как в исходном файле.

## Установка

```bash
pip install csvtidy
```

## Требования

- Python 3.10 или новее

## Возможности

- Удаляет полностью пустые строки.
- Удаляет дублирующиеся строки, то есть те, где совпадают все значения.
- Не меняет порядок столбцов.
- Режим предпросмотра `--dry-run` показывает статистику изменений и не записывает файл.

## Использование

### Базовый синтаксис

```bash
csvtidy input.csv [output.csv]
```

Если выходной файл не указан, результат перезаписывает исходный.

### Примеры

Очистить файл и сохранить результат в новый файл:
```bash
csvtidy data.csv data_clean.csv
```

Очистить файл «на месте» (in-place):
```bash
csvtidy data.csv
```

Посмотреть, сколько строк будет удалено, без изменения файла:
```bash
csvtidy --dry-run data.csv
```

Пример вывода `--dry-run`:
```
Будет обработано строк: 15 432
Пустых строк для удаления: 12
Дубликатов для удаления: 340
Итого останется строк: 15 080
Файл не изменён (режим --dry-run)
```

## Ограничения

- Файлы размером больше 2 ГБ пока не поддерживаются.
- Порядок и количество столбцов остаются прежними.
- Предполагается кодировка UTF-8.
