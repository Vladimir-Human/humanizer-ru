## Установка и быстрый старт

`rus-doc-anonymizer` — открытая Python-библиотека для обезличивания персональных данных в документах `.docx` и `.pdf`.

- Репозиторий: [github.com/sec-lab-ru/rus-doc-anonymizer](https://github.com/sec-lab-ru/rus-doc-anonymizer)
- Текущая версия: 1.4.0
- Дата релиза: 10 ноября 2026 года
- Мейнтейнер проекта: Алексей Петрович Круглов

---

### 1. Требования к окружению

Для `rus-doc-anonymizer` 1.4.0 нужно:

- Python 3.11 или выше. Python 3.10 и более старые версии не поддерживаются;
- не менее 4 ГБ оперативной памяти;
- входные документы в формате `.docx` или `.pdf`;
- для распознавания сканов и изображений внутри PDF — установленный в системе Tesseract OCR версии 5.3 или выше. Без него или с версией ниже 5.3 сканы могут обрабатываться неправильно или не обрабатываться вовсе.

> Ориентировочно, документ на 100 страниц обрабатывается за 3,5 секунды на обычном офисном процессоре.

---

### 2. Установка библиотеки

Устанавливайте пакет в изолированное виртуальное окружение.

#### Linux / macOS

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install rus-doc-anonymizer==1.4.0
```

#### Windows PowerShell

```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install rus-doc-anonymizer==1.4.0
```

Проверьте версию Python:

```bash
python --version
```

Она должна быть 3.11 или выше.

---

### 3. Установка и проверка Tesseract OCR

Если вам нужно обрабатывать отсканированные PDF или изображения внутри PDF, заранее проверьте, что в системе есть Tesseract OCR версии 5.3 или новее.

#### Проверка установленного Tesseract

```bash
tesseract --version
```

В выводе должна быть версия не ниже 5.3, например:

```text
tesseract 5.3.1
```

#### Установка Tesseract

##### Debian / Ubuntu

```bash
sudo apt update
sudo apt install tesseract-ocr
```

Затем проверьте версию. Если в репозитории дистрибутива она старше 5.3, поставьте Tesseract из официального источника или другим способом.

##### macOS

```bash
brew install tesseract
```

##### Windows

Tesseract можно поставить установщиком или через менеджер пакетов, например:

```powershell
choco install tesseract
```

После этого добавьте путь к исполняемому файлу `tesseract` в переменную окружения `PATH` и проверьте, что он доступен:

```powershell
tesseract --version
```

### 4. Быстрый старт

Минимальные примеры обезличивания документов.

#### Обработка DOCX

```python
from rus_doc_anonymizer import anonymize_file

anonymize_file(
    input_path="contract.docx",
    output_path="contract_anonymized.docx",
)
```

#### Обработка текстового PDF

```python
from rus_doc_anonymizer import anonymize_file

anonymize_file(
    input_path="report.pdf",
    output_path="report_anonymized.pdf",
)
```

#### Обработка отсканированного PDF

```python
from rus_doc_anonymizer import anonymize_file

anonymize_file(
    input_path="scan.pdf",
    output_path="scan_anonymized.pdf",
)
```

> Чтобы распознать текст в отсканированных PDF и изображениях, в системе должен быть Tesseract OCR версии 5.3 или выше.

---

### 5. Проверка работоспособности

Проверьте установку коротким тестом:

```python
from rus_doc_anonymizer import __version__

print(__version__)
```

Ожидаемый вывод:

```text
1.4.0
```

Если версия выводится, библиотека установлена и можно обрабатывать документы.
