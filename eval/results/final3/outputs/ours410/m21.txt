## Установка и быстрый старт

`rus-doc-anonymizer` — открытая Python-библиотека для обезличивания персональных данных в документах `.docx` и `.pdf`.

- Репозиторий: [github.com/sec-lab-ru/rus-doc-anonymizer](https://github.com/sec-lab-ru/rus-doc-anonymizer)
- Текущая версия: 1.4.0
- Дата релиза: 10 ноября 2026 года
- Мейнтейнер проекта: Алексей Петрович Круглов

---

### 1. Требования к окружению

Для `rus-doc-anonymizer` 1.4.0 нужно:

- Python 3.11 или выше. Python 3.10 и более старые версии не поддерживаются.
- Минимум 4 ГБ оперативной памяти.
- Входные документы в формате `.docx` или `.pdf`.
- Для распознавания сканов и изображений внутри PDF нужен установленный в системе Tesseract OCR версии не ниже 5.3. Без него или с версией ниже 5.3 обработка сканов может работать некорректно или не работать вовсе.

> Ориентировочная производительность: документ на 100 страниц обрабатывается примерно за 3,5 секунды на обычном офисном процессоре.

---

### 2. Установка библиотеки

Лучше устанавливать пакет в виртуальное окружение.

#### Linux / macOS

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install rus-doc-anonymizer==1.4.0
```

#### Windows PowerShell

```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install rus-doc-anonymizer==1.4.0
```

После установки проверьте версию Python:

```bash
python --version
```

Должна быть версия 3.11 или выше.

---

### 3. Установка и проверка Tesseract OCR

Если нужно обрабатывать отсканированные PDF или изображения внутри PDF, заранее проверьте, что в системе есть Tesseract OCR версии 5.3 или новее.

#### Проверка установленного Tesseract

```bash
tesseract --version
```

В выводе должна быть версия не ниже 5.3, например:

```text
tesseract 5.3.1
```

#### Установка Tesseract

##### Debian / Ubuntu

```bash
sudo apt update
sudo apt install tesseract-ocr
```

Потом проверьте версию. Если в репозитории дистрибутива более старая, установите Tesseract из официального источника или другим способом получите актуальную версию.

##### macOS

```bash
brew install tesseract
```

##### Windows

Лучше использовать установщик или менеджер пакетов, например:

```powershell
choco install tesseract
```

Затем добавьте путь к исполняемому файлу `tesseract` в переменную окружения `PATH` и проверьте, что он доступен:

```powershell
tesseract --version
```

### 4. Быстрый старт

Минимальный пример обезличивания документов.

#### Обработка DOCX

```python
from rus_doc_anonymizer import anonymize_file

anonymize_file(
    input_path="contract.docx",
    output_path="contract_anonymized.docx",
)
```

#### Обработка текстового PDF

```python
from rus_doc_anonymizer import anonymize_file

anonymize_file(
    input_path="report.pdf",
    output_path="report_anonymized.pdf",
)
```

#### Обработка отсканированного PDF

```python
from rus_doc_anonymizer import anonymize_file

anonymize_file(
    input_path="scan.pdf",
    output_path="scan_anonymized.pdf",
)
```

> Чтобы текст в отсканированных PDF и изображениях распознался, в системе должен быть Tesseract OCR версии не ниже 5.3.
