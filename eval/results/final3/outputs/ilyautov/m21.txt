## Установка и быстрый старт

Открытая Python-библиотека **`rus-doc-anonymizer`** обезличивает персональные данные в документах форматов **`.docx`** и **`.pdf`**.

- Репозиторий: [github.com/sec-lab-ru/rus-doc-anonymizer](https://github.com/sec-lab-ru/rus-doc-anonymizer)
- Текущая версия: **1.4.0**
- Дата релиза: **10 ноября 2026 года**
- Мейнтейнер проекта: **Алексей Петрович Круглов**

---

### 1. Требования к окружению

Требования для `rus-doc-anonymizer` 1.4.0:

- **Python 3.11 или выше.**  
  Python 3.10 и более старые версии не поддерживаются.
- **Минимум 4 ГБ оперативной памяти.**
- Форматы входных документов:
  - `.docx`
  - `.pdf`
- **Для распознавания сканов и изображений внутри PDF в системе должен быть установлен Tesseract OCR версии не ниже 5.3.**  
  Если Tesseract отсутствует или его версия ниже 5.3, обработка отсканированных документов может выполняться некорректно или не выполняться вовсе.

> **Ориентировочная производительность:** обработка документа на 100 страниц занимает примерно **3,5 секунды** на обычном офисном процессоре.

---

### 2. Установка библиотеки

Рекомендуется устанавливать пакет в изолированное виртуальное окружение.

#### Linux / macOS

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install rus-doc-anonymizer==1.4.0
```

#### Windows PowerShell

```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install rus-doc-anonymizer==1.4.0
```

После установки проверьте версию Python:

```bash
python --version
```

Версия должна быть **3.11 или выше**.

---

### 3. Установка и проверка Tesseract OCR

Для обработки сканов и изображений внутри PDF заранее проверьте, что в системе есть Tesseract OCR версии **5.3 или новее**.

#### Проверка установленного Tesseract

```bash
tesseract --version
```

В выводе должна быть версия не ниже 5.3, например:

```text
tesseract 5.3.1
```

#### Установка Tesseract

##### Debian / Ubuntu

```bash
sudo apt update
sudo apt install tesseract-ocr
```

После установки проверьте версию. Если в репозитории дистрибутива версия старше, установите Tesseract из официального источника или другим способом получите актуальную версию.

##### macOS

```bash
brew install tesseract
```

##### Windows

Установите Tesseract через установщик или менеджер пакетов, например:

```powershell
choco install tesseract
```

Затем добавьте путь к исполняемому файлу `tesseract` в переменную окружения `PATH` и проверьте, что он доступен:

```powershell
tesseract --version
```

### 4. Быстрый старт

Минимальные примеры обезличивания документов.

#### Обработка DOCX

```python
from rus_doc_anonymizer import anonymize_file

anonymize_file(
    input_path="contract.docx",
    output_path="contract_anonymized.docx",
)
```

#### Обработка текстового PDF

```python
from rus_doc_anonymizer import anonymize_file

anonymize_file(
    input_path="report.pdf",
    output_path="report_anonymized.pdf",
)
```

#### Обработка отсканированного PDF

```python
from rus_doc_anonymizer import anonymize_file

anonymize_file(
    input_path="scan.pdf",
    output_path="scan_anonymized.pdf",
)
```

> Для распознавания текста в отсканированных PDF и изображениях в системе должен быть доступен Tesseract OCR версии не ниже 5.3.
