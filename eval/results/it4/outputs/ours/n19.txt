# csvtidy

Утилита командной строки для быстрой очистки CSV-файлов. Удаляет пустые строки и дубликаты. Порядок столбцов остаётся исходным: колонки не сортируются и не переставляются.

## Установка

```bash
pip install csvtidy
```

## Требования

- Python 3.10 или новее

## Возможности

- Удаляет полностью пустые строки
- Удаляет дублирующиеся строки (полное совпадение всех значений)
- Сохраняет исходный порядок столбцов, структура не меняется
- Режим предпросмотра (`--dry-run`) показывает статистику изменений без записи файла

## Использование

### Базовый синтаксис

```bash
csvtidy input.csv [output.csv]
```

Если выходной файл не указан, результат перезаписывает исходный файл.

### Примеры

Очистить файл и сохранить результат в новый файл:
```bash
csvtidy data.csv data_clean.csv
```

Очистить файл «на месте» (in-place):
```bash
csvtidy data.csv
```

Посмотреть, сколько строк будет удалено, без изменения файла:
```bash
csvtidy --dry-run data.csv
```

Пример вывода `--dry-run`:
```
Будет обработано строк: 15 432
Пустых строк для удаления: 12
Дубликатов для удаления: 340
Итого останется строк: 15 080
Файл не изменён (режим --dry-run)
```

## Ограничения

- Файлы размером более 2 ГБ пока не поддерживаются
- Порядок и количество столбцов утилита не меняет: структура CSV остаётся такой же, как в исходном файле
- Предполагается кодировка UTF-8, стандартная для современных CSV
