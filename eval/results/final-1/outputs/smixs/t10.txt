## pgsnap

`pgsnap` создаёт снимки базы данных PostgreSQL по расписанию и автоматически удаляет старые.

### Требования и ограничения

| Параметр | Значение |
|---|---|
| Версии PostgreSQL | 14, 15, 16, 17 |
| Максимальный размер базы | 500 ГБ |
| Права суперпользователя | нужны только для первой настройки |

Для баз больше 500 ГБ `pgsnap` не подходит, их резервные копии лучше делать другими способами.

### Хранение снимков

По умолчанию `pgsnap` хранит 7 последних снимков. Когда создаётся новый снимок сверх лимита, самый старый удаляется.

Число снимков задаёт флаг `--keep`.

```bash
# хранить 14 последних снимков вместо 7
pgsnap --keep 14
```

Пример показывает только флаг `--keep`. Полный синтаксис запуска и настройку расписания смотрите в разделе об использовании.

### Права доступа

Суперпользователь PostgreSQL нужен только при первой настройке. Регулярные снимки создаются и без него, так что в повседневной работе хватит учётной записи с ограниченными правами.

Первоначальную настройку лучше сделать от суперпользователя, а расписание запускать от отдельного непривилегированного пользователя.
