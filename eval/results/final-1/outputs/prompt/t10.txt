## pgsnap

`pgsnap` делает снимки базы данных PostgreSQL по расписанию и сам удаляет старые.

### Возможности

- Снимки по расписанию.
- Автоматическая ротация: хранятся только последние снимки.
- Работает с PostgreSQL версий **14–17**.

### Требования и ограничения

| Параметр | Значение |
|---|---|
| Версии PostgreSQL | 14, 15, 16, 17 |
| Максимальный размер базы | 500 ГБ |
| Права суперпользователя | нужны только для первой настройки |

> **Важно:** `pgsnap` не рассчитан на базы больше 500 ГБ. Для них лучше использовать другие способы резервного копирования.

### Хранение снимков

По умолчанию `pgsnap` хранит **7 последних снимков**. Как только создаётся новый снимок сверх лимита, самый старый удаляется.

Число хранимых снимков задаётся флагом `--keep`:

```bash
# хранить 14 последних снимков вместо 7
pgsnap --keep 14
```

> Этот пример показывает только, как работает флаг `--keep`. Полный синтаксис запуска и настройку расписания смотрите в разделе об использовании.

### Права доступа

Права суперпользователя PostgreSQL нужны **только при первой настройке** `pgsnap`. Дальше регулярные снимки создаются и без них, так что в повседневной работе можно использовать учётную запись с ограниченными правами.

Лучше выполнить первоначальную настройку от суперпользователя, а расписание запускать от отдельного непривилегированного пользователя.
