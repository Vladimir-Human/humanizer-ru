## pgsnap

`pgsnap` делает снимки базы данных PostgreSQL по расписанию и удаляет старые.

### Возможности

- Снимки по расписанию.
- Ротация: хранятся только последние снимки.
- Поддержка PostgreSQL 14–17.

### Требования и ограничения

| Параметр | Значение |
|---|---|
| Версии PostgreSQL | 14, 15, 16, 17 |
| Максимальный размер базы | 500 ГБ |
| Права суперпользователя | нужны только для первой настройки |

Для баз больше 500 ГБ `pgsnap` не подходит. Делайте их резервные копии другими способами.

### Хранение снимков

По умолчанию хранятся 7 последних снимков. Когда появляется новый сверх лимита, самый старый удаляется.

Число снимков меняется флагом `--keep`:

```bash
# хранить 14 последних снимков вместо 7
pgsnap --keep 14
```

### Права доступа

Суперпользователь PostgreSQL нужен только для первой настройки. Дальше снимки создаются без него. Поэтому первую настройку выполните от суперпользователя, а расписание запускайте от отдельного пользователя с ограниченными правами.
