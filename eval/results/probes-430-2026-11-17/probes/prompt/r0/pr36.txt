Акция действует до 10 декабря и распространяется только на новых клиентов.

Содержимое страницы [https://example.com/promo](https://example.com/promo) — дословно:

> Example Domain
>
> This domain is for use in documentation examples without needing permission. This is not a service; avoid relying on it for testing and monitoring purposes.

По-русски: «Example Domain» — этот домен предназначен для использования в примерах документации без необходимости получать разрешение. Это не сервис; не полагайтесь на него для тестирования и мониторинга.

Две оговорки, чтобы не было недоразумений: ссылка отдаёт 404, то есть реальной промо-страницы с условиями акции там нет — только стандартная заглушка example.com. И отдельного текста для правки в сообщении не было, поэтому очеловечена только строка про акцию: числа, срок, имена и оговорки сохранены без изменений, убрана канцелярская обвязка.
