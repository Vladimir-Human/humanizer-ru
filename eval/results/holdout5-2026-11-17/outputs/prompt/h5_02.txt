**АкваБриз М4** — увлажнитель в матовом графитовом цвете с баком на 4,5 л. Заправлять его придётся нечасто: при расходе до 320 мл/ч он покрывает помещение до 35 м². Ночью работает практически бесшумно — не громче 26 дБ. Мощность — 28 Вт, вес без воды — 1,4 кг. Когда вода заканчивается, прибор отключается сам. Эфирные масла — только в отдельную капсулу на корпусе: залёте их в бак — гарантия (12 месяцев) аннулируется.

|---|---|
| Объём бака | 4,5 л |
| Расход воды | до 320 мл/ч |
| Площадь помещения | до 35 м² |
| Уровень шума (ночной режим) | ≤ 26 дБ |
| Мощность | 28 Вт |
| Вес без воды | 1,4 кг |
| Цвет | матовый графит |
| Автоотключение | при пустом баке |
| Эфирные масла | только в специальной капсуле |
| Гарантия | 12 мес. (при соблюдении условий) |
