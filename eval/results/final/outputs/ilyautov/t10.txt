## pgsnap

`pgsnap` создаёт снимки базы данных PostgreSQL по расписанию и автоматически удаляет старые.

### Возможности

- Создание снимков по расписанию.
- Автоматическая ротация: хранятся только последние снимки.
- Поддержка PostgreSQL версий **14–17**.

### Требования и ограничения

| Параметр | Значение |
|---|---|
| Версии PostgreSQL | 14, 15, 16, 17 |
| Максимальный размер базы | 500 ГБ |
| Права суперпользователя | нужны только для первой настройки |

> **Важно:** `pgsnap` не предназначен для баз размером более 500 ГБ. Для таких баз используйте другие способы резервного копирования.

### Хранение снимков

По умолчанию `pgsnap` хранит **7 последних снимков**. Когда создаётся новый снимок сверх этого лимита, самый старый удаляется.

Количество хранимых снимков меняется флагом `--keep`:

```bash
# хранить 14 последних снимков вместо 7
pgsnap --keep 14
```

> Пример показывает только использование флага `--keep`. Полный синтаксис запуска и настройки расписания смотрите в разделе об использовании.

### Права доступа

Права суперпользователя PostgreSQL требуются **только при первой настройке** `pgsnap`. После этого регулярные снимки создаются без них, поэтому для повседневной работы можно использовать учётную запись с ограниченными правами.

Рекомендуем выполнить первоначальную настройку от имени суперпользователя, а само расписание запускать от имени отдельного непривилегированного пользователя.
