# csvtidy

Утилита командной строки для быстрой очистки CSV-файлов. Удаляет пустые строки и дубликаты, порядок столбцов не меняет.

## Установка

```bash
pip install csvtidy
```

## Требования

- Python 3.10 или новее

## Возможности

- Удаляет полностью пустые строки.
- Удаляет дублирующиеся строки (совпадают все значения).
- Сохраняет исходный порядок столбцов.
- Режим предпросмотра `--dry-run` показывает статистику изменений, файл при этом не записывается.

## Использование

### Базовый синтаксис

```bash
csvtidy input.csv [output.csv]
```

Если выходной файл не указан, исходный файл перезаписывается.

### Примеры

Очистить файл и сохранить результат в новый файл:
```bash
csvtidy data.csv data_clean.csv
```

Очистить файл «на месте» (in-place):
```bash
csvtidy data.csv
```

Посмотреть, сколько строк будет удалено, не меняя файл:
```bash
csvtidy --dry-run data.csv
```

Пример вывода `--dry-run`:
```
Будет обработано строк: 15 432
Пустых строк для удаления: 12
Дубликатов для удаления: 340
Итого останется строк: 15 080
Файл не изменён (режим --dry-run)
```

## Ограничения

- Размер файла: файлы больше 2 ГБ пока не поддерживаются.
- Столбцы: порядок и количество столбцов не меняются, структура CSV остаётся прежней.
- Кодировка: предполагается UTF-8.
