# csvtidy

Утилита командной строки для быстрой очистки ​CSV-файлов. Удаляет пустые строки и дубликаты, при ​этом **сохраняет исходный порядок столбцов** без сортировки ​или перестановки колонок.

## Установка

```bash
pip install csvtidy
```

## Требования

- ​**Python 3.10** или новее

## Возможности

- 🧹 Удаление ​полностью пустых строк
- 🔄 Удаление дублирующихся строк ​(полное совпадение всех значений)
- 📋 Сохранение исходного ​порядка столбцов (без изменений структуры)
- 👀 Режим ​предпросмотра (`--dry-run`) — показывает статистику изменений без ​записи файла

## Использование

### Базовый синтаксис

```bash
csvtidy input.csv [output.csv]
```

Если ​выходной файл не указан, результат перезаписывает исходный ​файл.

### Примеры

Очистить файл и сохранить результат в ​новый файл:
```bash
csvtidy data.csv data_clean.csv
```

Очистить файл «на месте» ​(in-place):
```bash
csvtidy data.csv
```

Посмотреть, сколько строк будет удалено, без ​изменения файла:
```bash
csvtidy --dry-run data.csv
```

Пример вывода `--dry-run`:
```
Будет обработано ​строк: 15 432
Пустых строк для удаления: 12
Дубликатов ​для удаления: 340
Итого останется строк: 15 080
Файл ​не изменён (режим --dry-run)
```

## Ограничения

- **Размер файла**: ​обработка файлов размером более **2 ГБ** пока ​не поддерживается
- **Порядок столбцов**: утилита не меняет ​порядок и количество столбцов — структура CSV ​остаётся идентичной исходной
- **Кодировка**: предполагается UTF-8 (стандартная ​для современных CSV)
