# Предрегистрация когорты корпуса 2026-09-03 (формализация снимка 0/26)

Статус: формализующий предрег публикации. Хеш этого файла фиксируется в
RUNLOG прогона и METRICS.md ДО публикации чисел в main.

## 0. Честная нота о порядке (обязательна к цитированию)

Парный прогон (reference-реализация humanizer-ru и smixs/humanizer-ru,
пин 91f70df11f7fb30722e6fcf18803d402e2d86a53) выполнен 2026-09-03 на
корпусе полного дерева; настоящий документ формализует правила когорты
ДО публикации чисел, но ПОСЛЕ факта замера. Числа публикуются ровно как
измерены, не пересматривались и не пересчитывались задним числом;
optional stopping не применялся (прогон один, результат один). Правила
ниже codify фактически использованное построение корпуса, задокументированное
в `research/validation/README.md` ранее этого файла. Любой будущий замер
по этой когорте — только новым парным прогоном одной даты с сохранением
обоих JSON и новой датированной записью; этот снимок не перезаписывается.

## 1. Состав когорты (eligibility)

Корпус `eval/manifest.v1.json` (52 файла, каждый с sha256 и источником):

- **human (26)**: `research/validation/human/`. Критерии включения:
  (а) человеческое авторство (классика общественного достояния Wikisource
  либо текст, написанный проектом в регистре Википедии/Викиновостей для
  корпуса — статус каждого файла в `research/validation/README.md`);
  (б) русский язык; (в) связная проза (не код, не списки метаданных);
  (г) объём от 400 до 4000 символов после нормализации N1;
  (д) задокументированный provenance (источник + дата доступа).
- **ai (24)**: `research/raw/*` — выходы 7 семейств генераторов (alisa,
  copilot, deepseek, gemini, gigachat, grok, le-chat) с задокументированным
  происхождением; ожидаемые совпадения маркеров заявлены в манифесте
  (BOM le-chat, span-метки Gemini).
- **boundary (2)**: `research/validation/boundary/` — смешанные
  человек-машина контроли (benign-wiki-ref, emoji-zwj).

Не включаются: тексты без provenance; дубликаты по sha256; тексты вне
объёмной рамки; машиночитаемые фрагменты (код/конфиги).

## 2. Дедупликация

Единица — файл; идентичность — sha256 нормализованного содержимого.
Дубликаты по хешу в манифесте запрещены (гейт `scripts/check_corpus.py`
сверяет манифест с деревом; `scripts/check_confidence.py --check`
пересчитывает числа лидерборда из сырых JSON прогона). Пересечение с
прежней когортой 2026-08-12 (11+12+2) допустимо по файлам, но снимки
разных дат не смешиваются: каждая строка лидерборда привязана к дате
прогона и составу манифеста этой даты.

## 3. Лицензии

- Классика: общественное достояние (Wikisource), перераспространение
  свободное; источник и дата доступа — в `research/validation/README.md`.
- Тексты проекта в регистре Википедии/Викиновостей: написаны для корпуса,
  MIT проекта; дословными копиями страниц Википедии не являются (честная
  формулировка источников с v3.17.0).
- AI-выходы: зафиксированы как исследовательские артефакты с provenance
  (модель, дата, способ получения); лицензионная способность к
  перераспространению — по юрисдикции поставщика, файлы публикуются в
  составе репозитория с 2026-08 (исторические выпуски), претензий не
  заявлено; приватных данных нет (публичные промпты/ответы).
- Заимствованные фрагменты остаются под своими лицензиями; строка об этом
  — в разделе «Источники» README (v3.18.0).

## 4. Заморозка и метрики

- Манифест заморожен: `eval/manifest.v1.json` (52 записи, sha256 каждого
  файла); хеш манифеста фиксируется этим документом и RUNLOG.
- Метрика снимка: число человеческих файлов с ≥1 совпадением regex-слоя
  классов A/B; Wilson 95% CI обязателен; «FP = 0» без даты не пишется
  (ERRATA.md).
- Результат прогона 2026-09-03 (публикуется как измерен): reference —
  0 совпадений на 26 человеческих текстах (0/26, Wilson 95% CI
  [0%; 12.9%]), 11 на 24 AI-выходах (ожидаемые совпадения заявлены),
  2/2 boundary; smixs (пин 91f70df) — 75 совпадений по 13 файлам из 26
  (сумма правил, доля и CI не считаются), 150 на AI, 1/2 boundary.
  Сырые JSON: `research/leaderboard/reference-2026-09-03.json`,
  `research/leaderboard/smixs-2026-09-03.json`. Воспроизведение:
  `python3 eval/run_eval.py && python3 scripts/check_confidence.py --check`.
- Прав на «FP < 1%» этот снимок не даёт: верхняя граница Wilson 12.9%;
  для ≤1% требуется корпус от 381 текста (оси axes.json).
