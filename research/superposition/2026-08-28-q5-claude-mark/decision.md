# Q5: решение по коллапсу — водяной знак Claude

Вопрос: несёт ли генерируемый текст Claude (claude-opus-5, модель позднее
2026-08-02) наблюдаемый водяной знак в кодпоинт-слое, и переживает ли
след перезапись?

Дата предрегистрации: 2026-08-28 (`preregistration.md`; заморозка 65
файлов `evidence/corpus-freeze.sha256` до аудита; образцы заморожены
после генерации, до сканирования). Замеры: `evidence/audit.json`,
`evidence/rewritten-audit.json`, `evidence/rewrite-delta.json`.
Консилиум: `evidence/consilium.json` (qwen3.8-max + GLM-5.2,
единогласен).

## Правило коллапса (дословно из предрегистрации)

«Побеждает H-CODE, если в образцах Claude найден невидимый codepoint с
повторяемостью ≥ 2 из 3 образцов И отсутствием в фоне (33 файла).
Иначе побеждает H0: кодпоинт-слой чист — наблюдаемый знак отсутствует;
заявленная статистическая метка остаётся за пределами текстового аудита
(H-OOF рамка), процедура rewrite-guide не меняется, в реестр
llm-fingerprints вносится живой замер (провенанс: claude-opus-5 через
agentrouter, 2026-08-28; P-заявление дополняется наблюдением
«кодпоинт-слой чист на 3 образцах» — уровень O, не вердикт о знаке
в целом). При победе H-CODE: след прогоняется через слой A и
перезапись; H-SURV фиксирует снятие/переживание по факту; регистрация
маркера-кандидата — отдельным решением с рамкой «кандидат, не
верифицированный знак» (полный конвейер — вне этого цикла). Публичный
вердикт «знак снят/присутствует» НЕ выносится ни в каком исходе (нет
верификатора — H-OOF). Решение фиксирует запись границы, не продукт.»

## Матрица «гипотеза × доказательство»

| Гипотеза | Условие | Замер | Исход |
|---|---|---|---|
| H-CODE | невидимый codepoint ≥2/3 образцов И 0 в фоне | 0 невидимых во всех 3 образцах (sample_invisible_summary = {}) | антецедент ложен — не подтверждена |
| H0 | иначе | 0 невидимых сверх фоновых; скан маркеров 0; слой A снял 0 | **победитель** |
| H-SURV | только при H-CODE | не adjudicated (вакатна по правилу); вспомогательное предсказание «перезапись не вносит новых невидимых» — подтверждено (0) | dormant |

Аудит прогнозов: P1 ✓ (0 невидимых на 3 образцах — оба ревизора
подтвердили независимыми сканами); P2 ✓ (0 маркеров A/B); P3 ✓
(delta: n-граммы 18.5%, длина 1.069, «низкий» — архивировано в
`evidence/rewrite-delta.json` по требованию консилиума; 0 новых
невидимых в перезаписи); P4 ✓ по существу (фон: U+FEFF ×1 — BOM
le-chat/01; U+200D ×6 — легитимные эмодзи-соединители boundary и
human/11; NBSP-слои — в legit, не невидимые; формулировка прогноза
неточно предсказала раскладку ZWJ — зафиксировано как отклонение
перечисления, не исхода).

Консилиум: единогласен (H0 по букве правила; H-CODE антецедент ложен;
запись в реестр уровня O законна); qwen независимо верифицировал
заморозку 65/65 и таймлайн; GLM независимо просканировал образцы
(0 невидимых). Расхождения — только в перечне требований к гигиене
(все исполнены до коммита: delta архивирована, перезапись заякорена).

## Победитель и механическое срабатывание правила

**H0: наблюдаемый кодпоинт-слой текстов Claude (claude-opus-5, 3 образца,
канал agentrouter, 2026-08-28) чист** — ни одного невидимого/форматного
codepointа сверх фоновых; скан A.7 — 0 маркеров; детерминированный слой
A не находит, что снимать. Заявленный знак — статистический
(sampling-класс): он не наблюдаем побайтовым аудитом в принципе (рамка
H-OOF), поэтому H0 — это запись границы, НЕ вердикт «водяного знака
нет»: P-заявление Anthropic остаётся заявлением, процедура rewrite-guide
(глубокая перезапись текстов Claude моделью другого семейства) — без
изменений. Публичный вердикт «знак снят/присутствует» не выносится.

Исполнение решения:

1. **Реестр llm-fingerprints.md** — строка Claude дополняется живым
   замером (уровень O, провенанс, ссылка на evidence, запрет
   обобщения).
2. **BACKLOG.md** — строка «Живой образец Claude» закрывается.
3. Процедура rewrite-guide — без изменений (проверена живым прогоном:
   перезапись deepseek-v4-pro, delta «низкий», 0 новых невидимых).

## Отколлапсированные ветки

- **H-CODE (кодпоинт-след)** — убита замером: 0 невидимых в образцах
  (повторяемость ≥2/3 недостижима). Воскрешение: образцы Claude (прямой
  канал Anthropic или иной прокси) с систематическим невидимым
  codepointом, отсутствующим у других семейств на тех же промптах.
- **H-SURV (переживание следа)** — dormant (вакатна по правилу:
  проверяется только при следе). Воскрешение: подтверждение H-CODE на
  новом корпусе — тогда след прогоняется через слой A и перезапись.

## Победитель и живые рамки (вне отколлапсированных)

- **H0** — collapsed_winner (кодпоинт-слой чист; запись границы).
- **H-INV (артефакт прокси)** — жива как рамка: вывод ограничен «как
  получено через agentrouter»; прокси мог нормализовать байты, поэтому
  «чист» не переносится на прямой канал Anthropic. Закрытие: контраст
  с прямым каналом (недоступен).
- **H-OOF (статистический знак не наблюдаем побайтово)** — жива как
  рамка-граница; смена рамки возможна только появлением публичного
  верификатора (не существует на 2026-08-28).

## Ограничения решения

- 3 образца, 1 модель (claude-opus-5), 1 канал (agentrouter-прокси),
  3 коротких промпта серии 1: нулевая мощность обобщения; уровень O
  запрещает перенос на «модели с 2026-08-02» во множественном числе и
  на прямые каналы.
- Замороженный measure_q5.py не покрывает C0/C1-контроль, DEL,
  U+FFF0–FFF8 (закрыто внешними независимыми сканами обоих ревизоров —
  0 находок); гард ZWJ в аудите асимметричен гварду VS (для прозы без
  эмодзи нерелевантно).
- Перезаписан один образец (по предрегистрации); провенанс перезаписи —
  deepseek-v4-pro-0813 (гигиена «не-Claude» соблюдена).
