# Q6: анализ — разделение ядра и языкового слоя (для решения по каналу C1)

Дата: 2026-08-28. Статус: аналитическая записка; агент готовит анализ,
не код (правило спека Q6: реактивация — только подпись по GOVERNANCE.md,
канал C1/REBALANCE; Z1 мультиязык заморожен).

## Вопрос

Выносить ли языконезависимое ядро (дерево решений, рамка честности,
классы A/B) от русского языкового слоя (паттерны, морфология, лексика)?
BACKLOG: «Разделение ядра и языкового слоя, чтобы скилл можно было
перенести на другой язык».

## Анализ

**Что уже разделено де-факто.** Ядро живёт отдельно от языка сильнее,
чем кажется: SKILL.md (дерево, Главное правило, чек-листы) не содержит
русской лексики детекторов — только жанровые решения и процедуры;
справочники references/ — чистый языковой слой (лексика, образцы,
границы ложных срабатываний на русской типографике); скрипты несут
смешанный слой (механика + русская лексика в 582+315 строках).
Пороги дерева (T=3/K=2) — языконезависимые константы; жанровые
исключения (fiction/legal/academic) — универсальные категории.

**Что не разделено.** scan_soft_signals.py — сплав механики и лексики:
REGISTRY детекторов с русскими фразами, морфологические хвосты
(`[а-яa-z]*` в стемминге), кириллические границы слов
(`[а-яА-ЯёЁa-zA-Z\d-]`). check_markers.py: 40 маркеров, из них
подавляющее большинство — интерфейсные артефакты поставщиков
(языконезависимые: URI-схемы, PUA, невидимые символы), меньшинство —
русско-специфичные (мат-знаки, кальки). Граница проходит не «ядро vs
язык», а «механика vs лексика» внутри скриптов.

**Стоимость разделения.** Вынос лексики в данные (JSON-словари +
языковой модуль) затронет: оба скрипта (зеркала src/), selftest
(образцы), 17 справочников (перевод/дублирование), гейты паритета
(md↔py по русским фразам), демо. Оценка: сопоставимо с релизом 3.15.0
по охвату файлов — при нулевом внешнем спросе (Z1 заморожен, триггер
C1 не сработал).

**Инверсия (спек Q6).** Разделение раньше внешнего спроса —
преждевременная абстракция: умножит поверхность гейтов без
пользователей. Подтверждается фактами: спрос заморожен, стоимость
высока, ядро уже отделено документально.

## Рекомендация

Не разделять до триггера C1 (решение владельца в REBALANCE).
Каналу C1 передать: (а) ядро уже разделено документально (SKILL.md
без лексики; классы A/B универсальны; пороги константы); (б) главный
кандидат на будущий вынос — REGISTRY scan_soft_signals (582 строки
кириллицы) в данные; (в) 40 маркеров ~на 3/4 языконезависимы
(интерфейсные артефакты поставщиков) — перенос на другой язык
унаследует большинство маркеров автоматически; (г) жанровые исключения
— универсальные категории, словарь жанровых фраз — единственный
языковой блок в них.
