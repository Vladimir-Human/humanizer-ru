## Метрики (считаются один раз, одним скриптом)

Для каждой пары: lost/added/changed через facts_diff.diff(источник, перепись)
с тем же объёмом авторских категорий и фильтров, что в гейте check_examples
(payload маркеров и невидимые снимаются перед сравнением; имена не потеря,
если их слова остались подстрокой без регистра; негации и цитаты вне объёма).
Публикуются по каждому набору:
- доля пар с lost∪changed ≠ ∅ (основное число) + Wilson 95% CI;
- доля пар с added ≠ ∅ + Wilson 95% CI;
- суммарные счётчики по категориям lost/added;
- для S1 отдельно доля по парам без освобождающих меток.
Порогов «успеха» нет: это измерение, а не контроль; интерпретация —
описательно, с границами инструмента (синонимичные переформулировки без
удаления факта не ловятся).

## Чего не делаем

Не подбираем пары под желаемое число; не исключаем пары после прогона;
не меняем объём категорий после заморозки; не прогоняем повторно без
нового предрега.
