## Детекция машинного текста

- [bib:gltr2019] GLTR, Gehrmann, Strobelt, Rush, ACL 2019, arXiv:1906.04043, doi 10.18653/v1/P19-3019 — ПРОВЕРЕНО. Непрерывный сигнал top-k рангов без вердикта; прототип позиции проекта «показать, не судить».
- [bib:detectgpt2023] DetectGPT, Mitchell et al., ICML 2023, arXiv:2301.11305 — ПРОВЕРЕНО. Кривизна лог-правдоподобия; требует пару моделей — инвариант 7.
- [bib:fastdetectgpt2024] Fast-DetectGPT, Bao et al., ICLR 2024, arXiv:2310.05130 — ПРОВЕРЕНО. Дешевле DetectGPT; путь zero-shot через закрытые API (Glimpse) существует — отказ проекта по приватности и Главному правилу, не по невозможности.
- [bib:binoculars2024] Binoculars, Hans et al., ICML 2024, arXiv:2401.12070 — ПРОВЕРЕНО. Заявленный FPR 0,01% на английских данных; требует пары предобученных LM — инвариант 7.
- [bib:ghostbuster2024] Ghostbuster, Verma et al., NAACL 2024, arXiv:2305.15047 — ПРОВЕРЕНО. Только английский; раздел robustness — методика F3.

- [bib:chakraborty2023] Chakraborty et al., arXiv:2304.04736 — ПРОВЕРЕНО. Sample complexity: популяционная детекция возможна при n стремящемся в бесконечность — теоретическая опора F12 и противопоставление документной границе Sadasivan.
- [bib:liang2023] Liang et al., Patterns 4(7):100779, 2023, arXiv:2304.02819 — ПРОВЕРЕНО. 7 детекторов, 91 эссе TOEFL против 88 американских восьмиклассников: свыше половины TOEFL помечены как ИИ, средний FPR 61 процент, единодушно 19,8, хотя бы одним детектором 97,8; механизм — низкая перплексия. - [bib:dipper2023] DIPPER, Krishna et al., NeurIPS 2023, arXiv:2303.13408 — КОСВЕННО. Парафраз обнуляет детекторы.

## Водяные знаки и граница «без ключа не ловим»

- [bib:synthid2024] SynthID-Text, Dathathri et al., Nature 634:818-823, 2024, doi 10.1038/s41586-024-08025-4 — ПРОВЕРЕНО. Детектор требует ключ разработчика; байесовский выход watermarked/not/uncertain.
- [bib:kuditipudi2023] Kuditipudi et al., TMLR 2024, arXiv:2307.15593 — ПРОВЕРЕНО. Distortion-free знак без ключа статистически не виден сторонним наблюдателем по построению.
- [bib:cgz2023] Christ, Gunn, Zamir, 2023, arXiv:2306.09194 — КОСВЕННО. Криптографическая неотличимость без ключа.
- [bib:zhang2023] Zhang et al., 2023, arXiv:2311.04378 — КОСВЕННО. Даже с ключом сильный знак снимается атакующим с оракулом качества.
- [bib:anthropic2026wm] Anthropic, «How Claude’s text watermark works», 14.08.2026, обновлено 01.09.2026, anthropic.com/news/claude-text-watermark — ИСПОЛНИТЕЛЬ-2026-09-04 (HTTP 200): метод — версия SynthID-Text; применяется глобально на запуске моделям с 02.08.2026 (EU AI Act Article 50, Code of Practice); детектор-API — закрытый preview для организаций из списка EU, публично не выпущен; знак редок на фактических и корректорских проходах; вычитанный человеческий текст почти не несёт знака; код водянится слабо; знак не идентифицирует пользователя; Anthropic явно разграничивает watermark и «tells» (статистические привычки формулировок), которые ловят сторонние детекторы; знак не отличает «Claude написал» от «Claude сильно отредактировал»; лёгкая правка знак сохраняет, полная переписывание снимает.
- [bib:layerinflation2026] layer inflation атака на SynthID, arXiv:2603.03410 — ПРОВЕРЕНО существование; только как граница THREAT-MODEL.
- [bib:revdistfree2025] reverse-engineering distortion-free, arXiv:2502.18608 — ПРОВЕРЕНО существование; граница.
- [bib:mirrormark2026] MirrorMark multi-bit, arXiv:2601.22246 — ПРОВЕРЕНО существование; граница.
- [bib:imitate2024] machine-revised text detection, arXiv:2412.10432 «Imitate before detect» — КОСВЕННО. Выход humanizer-ов стал отдельным классом детекции; устойчивость к его детекции проект не измеряет (инвариант 2).

## Оценка переписывания без LLM-судей

- [bib:factcc2020] FactCC, Kryscinski et al., EMNLP 2020, arXiv:1910.12840 — ПРОВЕРЕНО. Схема трансформаций (отрицание, сущность, местоимение, число плюс два инвариантных контроля: парафраз и типографическая правка) — мутационная валидация экстрактора F1 без моделей.

- [bib:raid2024] RAID, Dugan et al., ACL 2024, arXiv:2405.07940, 2024.acl-long.674 — ПРОВЕРЕНО. recall при фиксированном FPR по 11 атакам; эмпирика: нейродетекторы без калибровки на целевом домене дают FPR выше 10 процентов — для русского ChatGPT-поколения калибровочных данных нет, импорт детектора невозможно честно откалибровать.
