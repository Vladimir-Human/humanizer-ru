## v3.8.0 — мягкий слой стал счётным

Regex-слой молчит на русских моделях: парный прогон 2026-07-26 не нашёл ни
одного артефакта копирования в выводах GigaChat и Алисы. Мягкие признаки —
четыре категории из references/ — до этой версии считались только глазами.

### Изменения

- Новый `scripts/scan_soft_signals.py`: кандидаты мягких признаков по четырём
  категориям, каждый паттерн один раз на текст, пороги дерева решений,
  жанровые исключения из `false-positives.md`, `--json`, `--plain-text`,
  `--fail-at`. Вердикта об авторстве нет по построению. Самопроверка —
  76 случаев, включая мета-тест на мёртвый детектор.
- Новый `scripts/check_all.py`: весь релизный чек-лист одной командой —
  27 гейтов, `--quick` — 23; исходы PASS, FAIL или SKIP с пояснением.
- `check_markers.py --scan` и `eval/run_eval.py`: вложенные совпадения больше
  не считаются дважды; оба используют один помощник `_line_matches`,
  пересечения без вложенности сохраняются.
- `check_perf.py`: без SyntaxWarning на Python 3.12+.
- CI: самопроверки сканера и раннера — отдельные шаги `validators.yml`.
- Документация сведена с фактическим составом репозитория: тринадцать
  скриптов в SECURITY, деревья README, REVIEW.md, BACKLOG, GAPS.

### Проверено

- `python3 scripts/check_all.py`: 27 гейтов, FAIL: 0, SKIP: 0.
- Человеческий контроль (11 файлов, нейтральный жанр): ноль мягких признаков.
- Выводы GigaChat и Алисы: кандидаты появляются там, где regex-слой молчит.
