# Лицензии и происхождение research-корпусов

Файл фиксирует лицензии и условия использования данных каталога research/
(поправка V2, П1). Правило проекта: лицензия прочитана и зафиксирована до
заморозки любого корпусного предрега; тексты корпусов не публикуются и не
покидают локальную машину, наружу выходят только агрегаты.

- Собственные тексты проекта и цитаты из публичных источников с атрибуцией
  в research/fixtures/marker-sources.json (source_url, accessed).
- Заимствований из MultiSocial нет: файлы записи Zenodo 13846152 restricted
  (доступ по запросу с академической почты), проект их не скачивал
  (проверено 2026-09-04: каталог не содержит файлов MultiSocial).

## research/validation/adversarial и boundary

## research/raw и производные корпусные страты

- CoAT (Shamardina et al. 2025): код репозитория Apache-2.0; HF-карточка без
  license-поля; человеческая сторона включает подкорпуса НКРЯ — только
  локально, наружу агрегаты; атрибуция обязательна.
- Taiga: сайт корпуса заявляет CC BY-SA 3.0 (проверено 2026-09-04);
  подкорпус для стратификации жанров фиксируется именем до заморозки
  предрега; условия ShareAlike соблюдаются (тексты не редистрибутируются).
- OpenCorpora: CC BY-SA; используется как архивный до-LLM корпус (отсечение
  не позже 2019-2020).
- MultiSocial: cc-by-4.0, но файлы restricted — в корпусах проекта
  отсутствует; строка OWNER-ACTIONS.md на случай доступа владельца.
- Mendeley 10.17632/4ynxfp3w53.2: CC BY 4.0 (явное поле Licence карточки).
