## v3.5.0 — новые маркеры и усиление проверок

Два новых маркера с опорой на неизменяемые источники, плюс несколько новых
CI-проверок, которые раньше работали только вручную.

### Изменения

Появились два новых жёстких маркера, оба с доказательствами из английской
Википедии: span-метки Gemini (`[span_N](start_span)`) и S3-ссылки Perplexity
(`ppl-ai-file-upload`). Теперь скилл ловит 38 regex-маркеров вместо 36.

Реестр источников дорос до 14 записей. Из него убраны все незавершённые
«ЗАДАЧА» — теперь каждая подтверждённая запись либо закрыта, либо честно
помечена ограничением. Валидатор падает, если в записи осталась открытая
задача, и предупреждает, если живой URL не перепроверяли больше полугода.

Добавлены три новые CI-проверки. Паритет md↔py следит, чтобы каждое
регулярное выражение было описано в справочнике — иначе regex может попасть в
код без документации. Регрессия корпусов гоняет human-тексты (ожидание: ноль
совпадений) и сырые ИИ-ответы (ожидание: только известный BOM). Самопроверка
стилевых маркеров тоже теперь в CI, а не только вручную.

Новый `check_corpus.py` проверяет корпуса валидации: человеческие тексты
должны давать ноль совпадений, ИИ-корпус — только известный BOM, а
граничные контроли — ровно заявленные совпадения.

`check_docs.py` стал строже: проверяет, что в CHANGELOG есть запись для
текущей версии, и больше не считает битой ссылкой то, что написано внутри
обратных кавычек.

Дерево решений в SKILL.md переработано. Юридические документы теперь
обрабатываются осторожно: удаляются только жёсткие артефакты, стилистика не
трогается. Появились ветки для возраста текста (до 2022 года — почти наверняка
человек) и для проверки с автором. Мягкие признаки теперь требуют совпадений
минимум из двух разных категорий — иначе это просто стилистическая
особенность.

В `false-positives.md` устранены противоречия в политике классов A/B.
Добавлена граница ложного срабатывания для ZWJ в эмодзи: `U+200D` входит в
состав семейных и флаговых эмодзи, и это нормально, а не след ИИ.

Счётчик паттернов исправлен: 37 (25 базовых + 12 расширений), а не 38, как
было написано раньше.

Атрибуции версий моделей в справочниках смягчены. Раньше в тексте были
утверждения про GPT-5.2, DeepSeek V4, o3/o4-mini — теперь это просто
наблюдения без привязки к конкретной версии, потому что подтверждённых
первичных источников для этих версий нет.

Добавлен `check_release.py`: собирает архив скилла детерминированно, только с
нужными файлами (без research/, tests/, .github/), и проверяет его на
path traversal, секреты в именах и дубликаты.

Появился нейтральный бенчмарк в `eval/`: манифест с sha256 всех файлов и
runner, который любой скилл-кандидат может прогнать одним командой.

### Проверка

Все локальные валидаторы зелёные: 38 из 38 regex проходят, паритет 38 из 38,
реестр 14 из 14, документация — 19 из 19 selftests без ошибок. Корпуса
валидации в норме: человеческие тексты — ноль совпадений, сырые ИИ-ответы —
только известный BOM, граничные контроли совпали. Архив скилла собран
детерминированно, SHA-256 в `research/CONSILIUM-REPORT.md`. Smoke-test
установки в `~/.claude/skills`, `~/.codex/skills` и `~/.agents/skills`
пройден.

### Совместимость

Minor-релиз: формат скилла и существующие правила совместимы. Новые маркеры
класса A усиливают детекцию, а правки дерева решений уточняют порог
вердикта — обратная совместимость не ломается.
