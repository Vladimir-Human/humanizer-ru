## v3.5.0 — новые маркеры с доказательствами и усиление CI

Релиз добавляет два маркера с неизменяемыми источниками и укрепляет
проверяемость. Скилл остаётся редактором текста, а не средством обхода
детекторов.

### Изменения

- Добавлены два маркера класса A: span-метки Gemini (`[span_N](start_span)`)
  и S3-ссылки Perplexity (`ppl-ai-file-upload`). Каждый опирается на
  неизменяемую ревизию английской Википедии, имеет fixtures и запись в
  реестре доказательств.
- Реестр источников расширен до 14/14. Открытые «ЗАДАЧА» в записях
  переписаны с явными ограничениями; валидатор падает на «ЗАДАЧА» в
  подтверждённой записи и предупреждает о живых URL старше 180 дней.
- Три новых CI-гейта: md↔py паритет (каждый regex задокументирован),
  регрессия корпусов валидации, самопроверка стилевых маркеров.
- Добавлен `check_corpus.py`: human-корпус должен давать 0 совпадений,
  raw-корпус — только известный BOM, boundary-контроли — ровно заявленные.
- `check_docs.py` усилен: проверка записи CHANGELOG для текущей версии,
  пропуск inline-кода при поиске битых ссылок.
- Дерево решений исправлено: юридические документы → только удаление
  артефактов класса A; добавлены ветки возраста текста и «спросить автора»;
  мягкие признаки требуют ≥2 категорий.
- Устранены противоречия политики A/B в `false-positives.md`; добавлена
  граница ложного срабатывания для ZWJ в эмодзи.
- Счётчик паттернов исправлен: 37 (25 базовых + 12 расширений), а не 38.
- Атрибуции версий моделей (GPT-5.2, DeepSeek V4, o3/o4-mini) в references
  смягчены до наблюдений без подтверждённой атрибуции.
- Добавлен `check_release.py`: детерминированная сборка архива скилла с
  allowlist (без research/, tests/, .github/), защитой от path traversal,
  секретов и дубликатов.
- Добавлен нейтральный бенчмарк `eval/`: manifest с sha256, runner для
  любого скилла-кандидата, воспроизводимый прогон.

### Проверка

- 38/38 regex-fixtures проходят, 38/38 паритет md↔py.
- 14/14 записей реестра закрывают гейт (2 warnings видимы и задокументированы).
- 19/19 документационных selftests, 0 ошибок.
- Корпус: human 0 совпадений, raw только известный BOM, boundary совпал.
- Архив скилла собран детерминированно, SHA-256 в `research/CONSILIUM-REPORT.md`.
- Smoke-test установки в `~/.claude/skills`, `~/.codex/skills`,
  `~/.agents/skills` пройден.

### Совместимость

Minor-релиз: формат Agent Skills и существующие правила совместимы. Новые
маркеры класса A усиливают детекцию; исправления дерева решений уточняют
порог вердикта, но не ломают обратную совместимость.
