# v3.5.0 — доказательные валидаторы и устранение противоречий политики

## Изменения

- Добавлены два маркера класса A с immutable-источниками: span-метки Gemini
  (`[span_N](start_span)`) и S3-ссылки Perplexity (`ppl-ai-file-upload`).
  Каждый имеет fixtures и запись в реестре доказательств.
- Реестр источников расширен до 14/14; устаревшие «ЗАДАЧА» переписаны с
  явным `warning_disposition`; валидатор запрещает открытые задачи в
  подтверждённыхных записях.
- Добавлены три новых CI-гейта: md↔py паритет regex, регрессия корпусов
  валидации (human 0, raw только BOM, boundary), самопроверка стилевых
  маркеров.
- `check_docs.py` усилен: проверка записи CHANGELOG для версии, пропуск
  inline-кода при поиске битых ссылок.
- Устранены противоречия политики A/B в `false-positives.md`: главное
  правило и алгоритм явно различают жёсткие артефакты (вердикт) и
  контекстные индикаторы (ручная проверка).
- Дерево решений исправлено: юр. документы → только класс A, ветка возраста
  текста, требование ≥2 категорий, «спросить автора».
- Счётчик паттернов исправлен: 37 (25 + 12), не 38. Атрибуции версий моделей
  смягчены до наблюдений без подтверждённой атрибуции.

## Проверка

- 38/38 regex-fixtures проходят.
- 38/38 паритет md↔py.
- 14/14 записей реестра источников закрывают гейт (2 warnings видимы и
  задокументированы).
- 19/19 документационных selftests.
- Корпус: human 0 совпадений, raw только известный BOM, boundary совпал.
- Пять локальных валидаторов и `check_corpus.py` зелёные.

## Совместимость

Minor-релиз: формат Agent Skills и существующие правила совместимы. Новые
маркеры класса A усиливают детекцию; исправления дерева решений и политики
A/B уточняют порог вердикта, но не ломают обратную совместимость.
