# Калибровка маркеров на AINL-Eval 2025

Порт подхода из [ilyautov/humanizer-ru](https://github.com/ilyautov/humanizer-ru)
(`eval/ainl_calibration.py`, `eval/AINL-CALIBRATION.md`) в этот репозиторий.
Здесь — корпусный способ померить ложные срабатывания мягких маркеров
(`scripts/scan_soft_signals.py`) на живом русском в масштабе и отделить маркеры
сути научного регистра от маркеров машинности.

## Что за корпус

[AINL-Eval 2025](https://github.com/iis-research-team/AINL-Eval-2025) — shared
task конференции AINL. Обучающая часть (`train`):

- 35 158 русских **научных аннотаций**;
- разметка по автору: `human` 8769, `gpt-4-turbo` 8801, `gemma-2-27b` 8790,
  `llama-3.3-70b` 8798;
- тот же датасет выложен организаторами на HuggingFace
  `iis-research-team/AINL-Eval-2025` (`train.csv`, `dev_full.csv`, `test.csv`).

Сплит `dev` (`dev_full.csv`) добавляет класс `unknown` — тексты модели, которой
нет в обучающей части (проверка на невиданный генератор); человеческий класс
там называется `abstract`.

## Лицензионный режим: «в репо только числа»

У выгрузки организаторов **нет файла лицензии**, поэтому корпус в репозиторий
не кладётся. Скрипт `eval/ainl_calibration.py` скачивает его **во временную
папку** (`tempfile.gettempdir()`), в репозиторий едет только человекочитаемый
отчёт с агрегатами. Корпус никогда не коммитится.

## Воспроизведение

Из корня репозитория, требуется сеть при первом запуске (внешний источник,
~50 МБ на сплит, два жанра на документ — несколько минут работы):

```sh
python eval/ainl_calibration.py                  # train, neutral + academic
python eval/ainl_calibration.py --csv путь\train.csv   # из локального файла
python eval/ainl_calibration.py --limit 4000     # быстрый прогон на выборке
python eval/ainl_calibration.py --split dev      # + невиданная модель `unknown`
python eval/ainl_calibration.py --selftest       # автономно, без сети
```

Что считает: для жанров `neutral` и `academic` долю **документов**, на которых
сработал каждый выбранный детектор `scan_soft_signals.py`
(`bureaucratese`/канцелярит, `est_avoidance`/является, `emdash_bold`/тире,
`significance`/значимость, `inanimate_intent`/неодушевлённый субъект). Доля на
`human` — ложные срабатывания (FP-по-человеку), доля на машинах — recall,
`AI/чел` — разделяющая сила. Сравнение `neutral` vs `academic` — эффект
**жанрового глушения** (какие маркеры суть норма научного регистра).

Если корпус недоступен — скрипт честно возвращает код 2 с инструкцией по
ручной загрузке, **без подделки чисел**.

## Чужое измерение ilyautov (до воспроизведения)

> **Пометка: это чужое измерение из ilyautov/humanizer-ru, у нас не
> воспроизведено.** Ниже — числа их прогона по тому же корпусу, приведены с
> атрибуцией и ждут проверки нашим скриптом (см. следующий раздел).

Из `eval/AINL-CALIBRATION.md` (ilyautov/humanizer-ru):

- **Канцелярит** — 64.1% человеческих документов (против 58–89% у моделей):
  канцелярит в научной аннотации — **норма жанра**, а не след машины.
- **«Является»** (`est_avoidance`) — 8.0% human против 0.1–3.0% у моделей:
  в этом домене маркер **человека**, модели почти не ставят.
- **Длинное тире** — 4.8% human против 0–0.9% у моделей: тоже маркер человека.
- **«Играет важную роль»** (`significance`) — AI/чел ≈ **5.7×** — сохраняет
  разделяющую силу.
- **Неодушевлённый субъект** (`inanimate_intent`) — AI/чел ≈ **4.4×** —
  сохраняет разделяющую силу (паттерн #55, добавлен по внешнему источнику).
- **Жанровое глушение** — доля документов с любым баном: **35.9% → 4.2%** при
  переходе от строгого режима к `--genre academic`.

Их вывод: в строгом режиме на научном тексте каталог классы не разделяет вовсе
(человек ловится не реже машин), отсюда жанровый фильтр. Дополнительно их прогон
на сплите `dev` (`unknown`) отрицательный: незнакомый генератор каталог не ловит
— маркеры описывают привычки конкретных семейств моделей, а не машинность как
таковую.

## Наш прогон

- **Статус:** воспроизведено. Корпус скачан, прогон выполнен.
- **Команда:** `python eval/ainl_calibration.py`
- **Дата/отчёт:** 2026-08-25, полные числа — `research/calibration/ainl-2025-2026-08-25.md`.

### Жанровое глушение (доля документов с хотя бы одним выбранным маркером)

| класс | neutral | academic | Δ, п.п. |
|---|---|---|---|
| human | 1.51% | 0.36% | −1.14 |
| gemma-2-27b | 0.63% | 0.63% | 0.0 |
| gpt-4-turbo | 2.87% | 2.86% | −0.01 |
| llama-3.3-70b | 0.98% | 0.61% | −0.36 |

Глушение снимает ложные срабатывания на человеке в **4×** (1.51% → 0.36%).

### По-детекторно (neutral; в academic глушатся является и значимость)

| маркер (детектор) | human | AI (средн.) | AI/чел |
|---|---|---|---|
| #8 канцелярит (bureaucratese) | 0.2% | 0.0% | 0.0 |
| #11 является (est_avoidance) | 1.2% | 0.1% | 0.1 |
| #16 тире (emdash_bold) | 0.0% | 0.0% | 0.0 |
| #2 значимость (significance) | 0.0% | 0.0% | — |
| #6b неодушевлённый субъект (inanimate_intent) | 0.2% | 1.4% | **8.6** |

**Вывод нашего прогона.** Разделяющую силу в этом домене показал только
**неодушевлённый субъект** (`inanimate_intent`, AI/чел ≈ 8.6×; у gpt-4-turbo 2.9%
против 0.2% у человека) — согласуется по направлению с чужим замером ilyautov
(4.4×). Остальные маркеры на научных аннотациях почти не срабатывают: наша
калибровка консервативнее, чем у ilyautov (канцелярит требует ≥3 вхождений на
документ, тире — плотности >6/1000 знаков на текстах ≥500 знаков, значимость —
≥2 вхождений). Поэтому абсолютные доли в разы ниже их 64.1%/8.0%/4.8%, при этом
направление «является» и тире бьют по людям не слабее, чем по машинам — то же,
что и у них. Чужие числа ждут точной пороговой сверки с нашей реализацией и
воспроизведены у нас только качественно.

## Границы вывода

- **Домен один.** Научные аннотации. Пользователи пишут посты и лендинги, а
  маркеры не переносятся между доменами дословно (`references/false-positives.md`
  §11, domain shift): канцелярит — норма научного регистра, не машинный след.
- **Модели поколения 2024–2025.** Формул категории M там, скорее всего, нет;
  корпус ничего не говорит о новых или постобработанных генераторах.
- **Машинные тексты постобработаны организаторами** (сняты зачины вроде
  «Конечно! Вот аннотация»), поэтому чатбот-маркеры корпус не покрывает.
- **Человеческие аннотации местами обрезаны** — маркер обрыва на полуслове
  (#25a) этим артефактом сборки не показывает свойства паттерна.
- **Мягкие признаки вердикта об авторстве не дают** (SKILL.md, Главное
  правило): эти числа калибруют FP/recall маркеров, а не границу детектора.
