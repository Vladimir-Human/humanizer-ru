# Закрытый разведочный пилот PERSONA.md (не полный A/B по протоколу)

Выборка: A=5, B=1, C=2 ответа; вопросы конфигураций совпадают лишь частично;
для B использована сокращённая версия SKILL.md (~1.5 КБ) вместо полной;
задержка не измерялась. Результаты показывают направление эффекта (C заметно
чище A, B - антипаттерн), но НЕ подтверждают критерии приёмки протокола
persona-ab-protocol.md. Для подтверждения нужен прогон по сокращённому
варианту 5x3 (см. протокол).

Дата: 2026-07-14
Модель: GigaChat (giga.chat, режим "Гига")
Клиент: giga.chat (веб, без логина)
Тест провёл: локальный агент через Playwright

## Конфигурации

- A — база: без инструкций (просто вопрос).
- B — SKILL.md prepend (краткая версия, ~1.5 КБ): текст скилла перед вопросом.
- C — PERSONA.md prepend (дословный текст после разделителя, ~800 байт).

Полный SKILL.md (13 КБ) не помещается в один промпт GigaChat. Для Config B
использована краткая версия с ключевыми правилами. Это ограничение теста.

## Вопросы

Использовано 5 вопросов из протокола (вместо 20). Для Config B и C — по 2
вопроса (Q1 и Q3), выбранные как репрезентативные (стилевой и фактический).

## Результаты: качество ответов

### Config A (baseline)
GigaChat без инструкций даёт длинные структурированные ответы: нумерованные
списки, заголовки, source-цитаты (rbc.ru, makfa.ru и т.д.), формальный тон.
Среднее нарушений: 18 на ответ.

### Config B (SKILL.md prepend)
Модель путается: пытается анализировать вопрос на AI-маркеры вместо того,
чтобы просто ответить. Ответ: "Столица Австралии - Канберра. В тексте нет
маркеров машинной генерации: отсутствуют УТМ-ссылки..." Модель смешивает
роли анализатора и собеседника. Наблюдение согласуется с гипотезой об
антипаттерне, но основано на единственном ответе.

### Config C (PERSONA.md prepend)
PERSONA.md даёт заметно более естественные ответы. Q1 (слепая печать):
"Забудь про тренажёры с прыгающими буквами, они только бесят. Скачай
нормальный софт..." — разговорный тон, первое лицо, ирония, без списков.
Q3 (Австралия): "Столица Австралии - Канберра. Многие думают, что это
Сидней или Мельбурн, но нет." — короткий, прямой, естественный.

## Критерии приёмки

1. Медианная задержка C <= 1.2 × A: **НЕ ПРОВЕРЕНО** — задержка не измерялась.
2. Сумма нарушений C <= 50% от A: **НЕ ПРОВЕРЕНО** — наборы вопросов и
   размеры выборок A/B/C различаются, поэтому суммы несопоставимы.
3. Факт-ошибок у C не больше, чем у A: **НЕ ПРОВЕРЕНО** — общий
   фактологический вопрос был только один; этого недостаточно для вывода.

## Вердикт

Это разведочный пилот, а не подтверждающий A/B-тест. Наблюдаемые ответы C
выглядят короче и разговорнее ответов A, но текущие числа описательные:
выборки неравны, вопросы совпадают частично, для B использована сокращённая
версия SKILL.md, задержка не измерялась. Поэтому ни один критерий приёмки
пока не считается выполненным, а причинный эффект PERSONA.md не подтверждён.
Для вывода нужен одинаковый прогон 5x3 по сокращённому протоколу. Результат
закрыт для v3.4.0 как `CLOSED_EXPLORATORY`: он не служит доказательством
эффекта PERSONA.md, не меняет правила скилла и не является заявлением о
качестве генерации. Повторное исследование нужно запускать как отдельный
предзарегистрированный эксперимент с одинаковыми вопросами, измеренной
задержкой и факт-контролем.
