# Предрегистрация F17: калибровка маркеров в отношения правдоподобия (2026-09-04)

Статус: заморожен до прогона (хеш в RUNLOG до первого запуска). Один проход.
Любой исход публикуется. Optional stopping запрещён.

## Вопрос

Каково отношение правдоподобия (LR) каждого маркера классов A/B как
свидетельства машинного следа: LR = P(находка | машинный текст) /
P(находка | текст-неноситель), с Wilson 95% CI по обеим долям?

## Популяции (те же источники, что F16; лицензии проверены там же)

- Машинная сторона: CoAT binary VALIDATION split, label == 1 (13 генераторов
  2021-2022; поколение устарело относительно 2024-2026 — помечается в отчёте).
- Неносители: страта coat-human-mix измерения F16 (12314 текстов) плюс
  registry-40; доли находок по маркерам берутся из снимка F16
  (research/fp-corpus-2026-09/extras.json), нового прогона неносителей нет.

## Метрика

Для каждого маркера: p1 = доля машинных текстов с находкой (новый проход по
машинной страте, один), p0 = доля неносителей с находкой (из снимка F16).
LR = p1 / p0; при p0 = 0 LR не определён — публикуется нижняя граница по
правилу трёх событий: p0_upper = Wilson-верх при 0 из n0, LR_lower = p1 /
p0_upper. Интерпретация по шкале доказательности: LR ниже 2 — свидетельство
слабое (маркер не калибруется как улика), 2-6 — ограниченное, 6-20 —
умеренное, выше 20 — сильное; класс A/B не меняется (риск-классы фиксированы
контрактом).

## Цели и пороги (до прогона)

Маркеры копипасты классов A (contentReference, cite_turn, turn_file и т.п.)
ожидаются с LR_lower выше 20 на машинной стороне CoAT; маркеры невидимых
символов класса B — с LR_lower выше 6. Маркеры ниже порога публикуются как
некалиброванные с планом (F9/BACKLOG), задним числом не чинятся.
