# Кросс-семейная проверка прогона 2026-08-10-deep-rewrite (2026-08-10)

## Зачем

Основная панель прогона набрана из той же модели, что исполняла ветки:
возможно самопредпочтение. Проверка независимым семейством снимает
этот вопрос.

## Кто судил

Панель из трёх GLM-5.2 (Zhipu, dashscope) по тем же обезличенным парам
и той же инструкции. Попытки взять судей из других семейств:
cerebras/zai-glm-4.7, dashscope/kimi/kimi-k3, dashscope/MiniMax/MiniMax-M3,
cerebras/gpt-oss-120b не ответили в разумное время (сессии висят без
единого сообщения); dashscope/qwen-flash ответил, но выдал механическое
чередование A/B с шаблонными note — вердикт отклонён как ленивый
(файл сохранён с суффиксом REJECTED-lazy). GLM-5.2 отработал все три
голоса содержательно: попарная конкретика, независимые расхождения
(P009: два голоса за A, один за B).

## Результат

| Панель | Семейство | Читаемость (with/without/tie) | Потери смысла |
|---|---|---|---|
| Основная (3 судьи) | семейство исполнителя | 5 / 0 / 5 | 0 |
| GLM-5.2 x3 | Zhipu (независимое) | 5 / 0 / 5 | 0 |

Совпадение счёта полное; расхождения внутри панелей — по одной паре
в каждой. Самопредпочтение не объясняет результат: независимое семейство
видит ту же картину. Отдельная находка GLM-панели: в ветке без скилла
на паре слепопечати вместо «зрячей печатью» написано «печатью глядя» —
ошибка перефразирования, учтена голосами за ветку со скиллом.

## Границы

Панель GLM набрана одним семейством и одной моделью: три голоса дают
большинство, но не разнообразие архитектур. Полноценная кросс-панель
требует доступности других семейств в рантайме; на момент прогона они
не отвечали. Вердикты обеих панелей и ключ — рядом с пакетом прогона.
