# LICENSES-EXTERNAL — внешние корпусы: лицензии и права на фрагменты

Дополнение к П14 поправки V2 (поручение владельца 2026-09-04): по каждому
внешнему источнику — лицензия, право редистрибуции фрагментов в
research/validation/human/, что публиковать нельзя, дата проверки, ссылка на
первоисточник. Неясное право помечено «проверить у правообладателя», а не
догадкой. Ограниченные источники помечены «только локально, наружу агрегаты».
Общая дата проверки строк: 2026-09-04 (HTTP-доступ к первоисточникам в этой
сессии, кроме помеченных иным образом).

Факт о собственном human-корпусе: research/validation/human (26 файлов) —
классика в общественном достоянии (Тургенев, Гоголь, Достоевский, Толстой,
Пушкин, Лермонтов и т.д., авторы умерли в XIX веке) и синтетические образцы
проекта; фрагментов внешних корпусов с неясной лицензией там нет.

## CoAT (RussianNLP/CoAT, HF datasets/RussianNLP/coat)

- Лицензия: код репозитория Apache-2.0 (github.com/RussianNLP/CoAT, файл
  LICENSE, проверено через API 2026-09-04); HF-карточка явного license-поля
  не несёт (проверено 2026-09-04).
- Состав человеческой стороны: шесть доменов, включая подкорпуса НКРЯ,
  Википедию, новости, дневники, машинный перевод.
- Право редистрибуции фрагментов в research/validation/human: НЕ
  реализовано и не требуется (human-корпус — общественное достояние); для
  гипотетического включения фрагментов CoAT право неясно из-за смеси
  доменов — «проверить у правообладателя» по каждому домену отдельно.
- Публиковать нельзя: тексты CoAT и их фрагменты; наружу только агрегаты
  измерений (доли, CI), что и сделано в research/FP-CORPUS-2026.md.
- Режим: только локально, наружу агрегаты.
- Первоисточник: https://huggingface.co/datasets/RussianNLP/coat ;
  https://github.com/RussianNLP/CoAT

## MultiSocial (Zenodo 13846152)

- Лицензия записи: CC BY 4.0; НО файлы restricted: выдача по запросу с
  официальной академической почты и research-only условиями (проверено
  2026-09-04: API записи и страница записи; перепроверено живым Zenodo API
  в тот же день: license.id = cc-by-4.0, access_right = restricted,
  дисклеймер записи дословно — «The intended use if for non-commercial
  research purpose only» [sic], около 8% семплов потенциально токсичны по
  их классификатору, анонимизация может быть неполной).
- Проект файлы не скачивал; в research/validation/human и иных каталогах
  репозитория данных MultiSocial нет (проверено отсутствием файлов).
- Право редистрибуции фрагментов: при получении доступа — условия записи
  (research-only, без ре-шеринга): фрагменты публиковать нельзя;
  «проверить у правообладателя» до любого использования.
- Режим: только локально, наружу агрегаты (после возможного получения
  доступа владельцем с академической почтой — OWNER-ACTIONS.md).
- Первоисточник: https://zenodo.org/records/13846152
