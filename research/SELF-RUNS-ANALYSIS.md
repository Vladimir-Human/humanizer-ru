# Проверяемая гуманизация против «99% bypass»: разбор самопрогонов

Дата: 2026-08-13. Только механические оси (решение Д1). Этот документ —
не реклама и не сравнение качества перезаписи: он показывает, какие
заявления о гуманизации можно проверить, а какие нет.

## Что заявляют одноимённые проекты

- [ilyautov/humanizer-ru](https://github.com/ilyautov/humanizer-ru) (описание
  репозитория, сверено с GitHub API 2026-08-13): «Убирает 54 признака
  нейросети… Метит в то, что меряют GPTZero, DivEye, RuBERT: поднимает
  perplexity и burstiness».
- [smixs/humanizer-ru](https://github.com/smixs/humanizer-ru): «убирает 37
  признаков AI-генерации… humanizer & detector».

Ключевой заявленный эффект — изменение вердиктов сторонних детекторов.
Этот эффект непроверяем в публичном контуре: версии детекторов меняются,
пороги не публикуются, а «поднял perplexity» не означает «стало лучше» —
так же ведёт себя ухудшение текста.

## Что проверяемо и что замеряет этот проект

Механические оси на нейтральном корпусе (`eval/manifest.v1.json`, 12
AI-выводов + 11 человеческих текстов + 2 boundary-контроля):

| Ось | Зачем | Наш результат (reference) |
|---|---|---|
| Ложные срабатывания на человеческих текстах | «не портить живое» | 0 |
| Совпадения на boundary-контролях | устойчивость к граничным случаям | 2/2 |
| Снятие копипаст-маркеров | полнота чистки артефактов | 100% (прогоны markers) |
| Чистота фактов | перезапись не дописывает фактов | 100% в приёмочных прогонах (известное слепое пятно задокументировано) |
| Ложные правки человеческих текстов | скилл не трогает живое | 0 |

Сырые прогоны: `research/leaderboard/` (воспроизводятся из репо).
Контрфакт «просто попросить LLM переписать» (`research/F4-preregistration-
2026-08-13.md`, два прогона 2026-08-13): снятие маркеров у простого
промпта — те же 100%, факт-чистота — паритет; разница одна и она
измерима: LLM переписывает человеческие тексты, если её просят, а скилл
их не трогает (ложные правки 0 против 3 и 0 против 2).

## Что из этого следует

1. «Снимаем N признаков» — заявление о внутреннем счётчике, не о
   результате: любой пересказ снимает копипаст-разметку.
2. «Поднимаем perplexity/burstiness» — не валидируемая ось качества;
   публично не проверяется никем.
3. Разница между инструментами лежит в том, что можно пересчитать:
   ложные правки, чистота фактов, ложные срабатывания. Это и публикует
   LEADERBOARD.md — без вердиктов «кто лучше», с сырыми данными.

## Воспроизведение

```sh
python3 eval/run_eval.py > research/leaderboard/reference-<дата>.json
python3 eval/run_eval.py --candidate eval/candidates/smixs_runner.py > research/leaderboard/smixs-<дата>.json
```
