# Изыскания: как читать эту папку

Папка — журнал наблюдений и проверок. Часть документов живые, часть — архив
конкретных прогонов; архив не редактируется, новые наблюдения вносятся
в BACKLOG.md и GAPS.md в день находки.

## Живые документы

| Файл | Назначение |
|---|---|
| `BACKLOG.md` | открытые хвосты и отклонённые пункты |
| `METRICS.md` | еженедельные метрики и цели 90 дней (SPEC_MERGED, Приложение Г) |
| `REBALANCE.md` | перевзвешивание реестра направлений: срез 2026-08-13, контроль 2026-11-12 |
| `MAINTENANCE-MODE.md` | критерии и порядок стоп-лосса L1 (записаны до наступления триггеров) |
| `SELF-RUNS-ANALYSIS.md` | публичный разбор самопрогонов: проверяемое против непроверяемого (только механика) |
| `GAPS.md` | журнал наблюдений; условия переоткрытия закрытых исследований |
| `fixtures/marker-sources.json` | реестр доказательств маркеров |
| `validation/` | корпус валидации: человеческие тексты, контроли границ |

Повторные `source_url` в реестре осознанны: одна протёкшая ревизия может
нести несколько разных форм артефактов (например, PUA-обёртки и метки
`turn0searchN` в одном тексте). Каждая такая запись несёт
`warning_disposition`, а предупреждение валидатора оставлено постоянным
напоминанием проверять общность источника.

## Агентские прогоны (`agent/`)

Компактные отчёты независимого goal-driven контура (август 2026):
`P3-exp1-report.md`, `G5-exp1-report.md`, `P4-do-no-harm-report.md` — прогоны
с предрегистрацией и слепыми панелями; `HYPOTHESES.md` — состояние
суперпозиции S1–S6; `TERMINAL-narrowed-product.md` — принятый терминальный
исход. Сырые артефакты (манифесты, хеши, пакеты, вердикты) — в рабочем
пространстве агента.
