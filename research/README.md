# Изыскания: как читать эту папку

Папка — журнал наблюдений и проверок. Часть документов живые, часть — архив
конкретных прогонов; архив не редактируется, новые наблюдения вносятся
в BACKLOG.md и GAPS.md в день находки.

## Живые документы

| Файл | Назначение |
|---|---|
| `BACKLOG.md` | открытые хвосты и отклонённые пункты |
| `GAPS.md` | журнал наблюдений; условия переоткрытия закрытых исследований |
| `fixtures/marker-sources.json` | реестр доказательств маркеров |
| `validation/` | корпус валидации: человеческие тексты, контроли границ |

## Архив прогонов и проверок

| Файлы | Что это |
|---|---|
| `RELEASE-DRAFT-v*.md` | черновики релизных заметок; после выпуска — история |
| `AUDIT-*.md`, `CONSILIUM-REPORT.md`, `FINAL-PREMERGE-REPORT.md` | разовые отчёты аудитов |
| `blind-eval-*.md` | разборы слепых парных прогонов и судейских коллизий |
| `crossfamily-validation-2026-08-10.md`, `judge-rubric-collision-2026-08-10.md`, `marker-removal-analysis-2026-08-10.md` | анализы прогонов 2026-08-10 |
| `protocols/` | протоколы тестов (Le Chat, persona A/B) |
| `raw/` | сырые ответы моделей, захваченные без правок |
| `ab/` | пилот persona A/B (закрыт как exploratory) |
| `core-language-split.md` | проработка отделения ядра от языкового слоя |
