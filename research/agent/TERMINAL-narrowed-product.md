# Терминальный исход: narrowed_product (2026-08-14)

По спецификации goal-driven контура исследование завершается одним из трёх
исходов. Принят **narrowed_product**: польза доказана в конкретном режиме,
scope и документация согласованы.

**Доказанный режим продукта:** единый поток перезаписи по скиллу +
детерминированный lint-слой снятия артефактов.

**Подтверждённые оси** (все прогоны предрегистрированы и слепо судились):
1. Снятие машинных артефактов — 100% во всех прогонах.
2. Предпочтение слепых панелей: перезапись > исходник (9/9, p=0.0039)
   и > детерминированной чистки (14/14, p=0.000122, зонд 0/30, согласие
   двух модельных семей).
3. Нулевой вред человеческому тексту: 0 ложных правок на 17 контролях
   против 17/17 у сильных контрфактов; повреждение голоса 2/6 у контрфакта,
   0 у скилла.
4. Факт-чистота 100%, потери смысла 0.
5. S3 (разделение режимов) отклонено данными: split проигрывает 0/19
   и теряет контент; Fact Lock точен (recall 100%), но как посредник
   деструктивен.

**Что не заявляется.** Человеческое предпочтение: измерений с живыми судьями
не было, все панели модельные. Валидация продукта людьми — отдельный шаг,
если владелец решит его провести.

**Согласование scope.** Тесты и документация покрывают доказанный режим;
anti-evasion политика неизменна; детекторы — не метрика.
