# P3-exp1: скилл против сильного нейтрального baseline (exploratory)

**Вопрос.** Даёт ли перезапись по скиллу текст, который слепой судья
предпочитает нетронутому исходнику и сильному baseline «LLM без скилла»,
при нулевом вреде человеческим текстам?

**Дизайн.** Три ветки: A (исходник), B (скилл, пин 3941802), C (та же модель
с нейтральной инструкцией «перепиши живым языком, сохрани факты»). Корпус:
9 AI-выводов + 11 человеческих контролей, sha256 заморожены до генерации.
Судьи: 3×Qwen3.7-max на сравнение, слепые пакеты с криптостойким порядком.

**Механика.**

| Ось | Скилл (B) | Без скилла (C) |
|---|---|---|
| Снятие маркеров | 100% | 100% (ось не различает) |
| Факт-чистота | 100% | 77.8% (C приписал 2 названия книг) |
| Ложные правки человеческих текстов | **0 из 11** | **11 из 11** |
| Потери смысла | 0 | 0 |

**Слепое судейство.** B > A: 9/9 (p=0.0039, значимо). B vs C: main-сессия
3/3/3 (p=1.0), probe-сессия 5/2/2 (p=0.453) — различия нет; зонд шума:
8/20 пар сменили победителя между сессиями.

**Вывод.** Скилл сильно лучше «ничего не делать» и не лучше простой сильной
инструкции по читаемости; его отличие — безопасность: 0 ложных правок против
11 и 0 дописанных фактов против 2. Человеческое предпочтение не измерялось
(панель модельная) — прогон exploratory.

**Ограничения.** Одна модель-генератор; 9 AI-пар; панель односемейная.
Полный отчёт с аддендумом о маркировке сессий — в рабочем пространстве
агента (runs/P3-exp1/REPORT.md).
