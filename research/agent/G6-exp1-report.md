# G6-exp1: разделение режимов против единого потока (exploratory)

**Вопрос.** Даёт ли разделение Fact Lock (проверка фактов) и Style Assist
(перезапись стиля) лучший результат, чем единый поток?

**Дизайн.** Ветки: U (единый поток — замороженные выходы G5), S (два шага:
Fact Lock с офлайн-флагованием источников по ground truth из 35 целей →
Style Assist с фактами только из отчёта). Корпус G5 (19 AI + 11 human),
промпты и ground truth заморожены хешами, изоляция исполнителя аттестована.
Судьи: 3×Qwen3.7-max + зонд.

**Результат.** U > S: **19/19 AI-пар** (подгруппа с артефактами 14/14,
p=0.000122; агрегат p≈4×10⁻⁶). S вырезал 140 строк исходников, из которых
только 7 относились к помеченным источникам — 133 строки легитимного
контента потеряны (гейт meaning_loss провален). Fact Lock сам по себе
точен: recall 100% по ground truth (34/34 уникальных целей).

**Вывод.** Разделение проигрывает единому потоку с большим отрывом:
инвентарь фактов как обязательный посредник работает прокрустовым ложем.
S3: зафиксирована первая из двух независимых попыток фальсификации; ресурс
на S3 не выделяется. Прогон exploratory, панель модельная.
