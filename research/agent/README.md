# Агентские прогоны (goal-driven контур, август 2026)

Сводка независимого исследовательского контура по спецификации владельца
(goal-driven, суперпозиция гипотез S1–S6, жёсткие гейты). Сырые артефакты
прогонов — манифесты, хеши, слепые пакеты, вердикты судей, атомарный ledger —
хранятся в рабочем пространстве агента и не публикуются целиком; здесь —
компактные отчёты с полными числами и честными ограничениями.

Как читать: P3-exp1 — скилл против сильного baseline; G5-exp1 — скилл против
детерминированного lint; P4 — do-no-harm корпус; G6 — разделение режимов; HYPOTHESES — состояние
суперпозиции; TERMINAL — принятый терминальный исход.

Все прогоны предрегистрированы (протоколы, манифесты, хеши до генерации),
ревьюированы двумя независимыми модельными семьями (методолог GLM-5.2,
red-team Qwen3.8-max) и слепо судились панелями семьями, отличными от
генераторов.
