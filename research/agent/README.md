# Исследовательские прогоны (август 2026)

Компактные отчёты о различающих экспериментах над редакторским режимом
скилла. Каждый прогон предрегистрирован (протокол и манифест заморожены
хешами до генерации), прошёл независимое ревью двух модельных семей
и слепо судился панелями, не связанными с генераторами.

Как читать: P3-exp1 — скилл против сильного baseline; G5-exp1 — скилл против
детерминированного lint; G6-exp1 — единый поток против разделения режимов;
P4 — do-no-harm корпус; HYPOTHESES — направления проверки S1–S6 и их статусы;
TERMINAL — provisional proposal режима продукта; ARTIFACTS-HASHES —
неизменяемые хеши артефактов для внешней проверки.
