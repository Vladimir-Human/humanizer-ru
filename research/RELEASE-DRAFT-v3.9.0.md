## v3.9.0 — доказательства стали первичными

Черновой вариант. Номер версии и решение о релизе — за владельцем
(MISSION §2.5); текст можно переименовать под любой номер.

Реестр доказательств вырос с 14 до 32 записей из 38: у почти каждого
маркера теперь есть неизменяемый источник, дословный образец и класс
доказательства. Справочники разбиты по частям и перестали упираться в
бюджет. Правила скилла не менялись.

### Публикация

Тег v3.9.0 и все коммиты — только локально; публикация — операция владельца
(MISSION §2.2). Финальная связка: правки аудита закоммичены, архив
пересобран после них, тег переставлен на голову, содержащую все правки.

1. `git push origin main` — чистый fast-forward; история проверена аудитом
   (секретов и служебных каталогов нет).
2. `git push origin v3.9.0` — аннотированный тег (GPG-подписи нет; README
   обещает аннотированные теги, не подписанные).
3. На GitHub создать выпуск из тега v3.9.0 и приложить архив под именем
   `humanizer-ru.zip` — это имя обещает README и под ним собирает CI
   (`release-check.yml`); локальный `dist/humanizer-ru-v3.9.0.zip` собран
   из того же коммита и байт-идентичен CI-сборке. SHA-256 приложенного
   файла сверить с указанным выше.
4. CI при пуше тега прогонит release-check (включая ASCII-гейт адресов)
   и приложит `humanizer-ru.zip` к артефактам прогона — резервная копия
   того же архива.
5. Каталог skills.sh после пуша подхватит версию v3.9.0 автоматически;
   бейдж числа установок в README статический (401+ на 2026-08-07) и сам
   не обновится.
