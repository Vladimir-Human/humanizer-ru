## v3.9.0 — доказательства стали первичными

Черновой вариант. Номер версии и решение о релизе — за владельцем
(MISSION §2.5); текст можно переименовать под любой номер.

Реестр доказательств вырос с 14 до 32 записей из 38: у почти каждого
маркера теперь есть неизменяемый источник, дословный образец и класс
доказательства. Справочники разбиты по частям и перестали упираться в
бюджет. Правила скилла не менялись.

### Изменения

- Реестр доказательств: 14/38 → 32/38. Восемнадцать новых записей —
  immutable-ревизии Википедии (EN и разделы fr/es/it) и снимок Wayback
  Machine; шесть записей базового набора (`ref_name_search`,
  `grok_card_tag`, `deepseek_line_ref`, `attached_web_bracket`,
  `placeholder_url`, `perplexity_s3`) усилены со secondary до класса
  primary; источники `utm_copilot` и `placeholder_date` зафиксированы на
  /blob/-снимках коммитов GitHub без смены класса.
  Остаток: шесть legacy-маркеров без живых образцов в
  доступных публичных архивах (задокументировано в журнале прогона) и две
  вторичные записи с зафиксированной недостижимостью первоисточников.
- `scripts/check_fixture_sources.py`: снимки Wayback Machine
  (`web.archive.org/web/<метка времени>/`) признаны неизменяемыми
  источниками; в самопроверку добавлен один кейс на Wayback (итого 21).
- Справочники: `references/chatbot-artifacts.md` разбит на индекс и три
  части, `references/test-fixtures.md` — на индекс и две части;
  предупреждений бюджета ноль.
- Новый `scripts/check_reference_maps.py`: единственность заголовков
  разделов в разбитых справочниках и живость имён частей в индексах.
- Новый `scripts/check_own_style.py`: порог 90 мягких признаков на прозу
  поставки (SKILL.md, README, CONTRIBUTING, PERSONA, docs/REVIEW.md,
  документация eval); справочники и CHANGELOG вне порога по обоснованию в
  `research/BACKLOG.md`. Итого гейтов: 27 → 31.
- SKILL.md сжат с ~4567 до ~4442 токенов (ниже предупреждающего порога 90%)
  без изменения содержания: правила изоляции, принцип «не дописывать
  факты», чек-лист и дерево решений сохранены построчной сверкой.
- `tests/fixtures/openai-pua.txt`: дословный срез ревизии-источника с
  двенадцатью живыми PUA-байтами — запись `openai_pua` проверяема без сети.
- Новый аналитический документ `research/core-language-split.md`: что в
  скилле языковое, что переносимое ядро, и в каком порядке скилл
  переносился бы на другой язык (первый шаг пункта P3, файлы не
  перемещались).
- Второй парный прогон слепой оценки `eval/runs/2026-08-07-second`
  (6 пар: GigaChat, Le Chat, два человеческих контроля): механические
  метрики — правки без дописанных фактов 100% со скиллом против 75% без,
  ложных правок в человеческих текстах 0/0. Судейская часть (читаемость,
  потеря смысла) оставлена человеку-судье: пакет `.agent/blind-packet-second`
  вне поставки, в коммите — только данные прогона и механика.
