# Журнал тестов Le Chat

> **Статус: прогоны не выполнены.** chat.mistral.ai заблокирован Cloudflare
> (403, бесконечная проверка безопасности) при доступе через Playwright.
> Прогоны проводятся вручную после прохождения проверки в браузере.

## Минимальные требования

- >= 5 промптов x 3 режима (веб-поиск / без поиска / Libraries) = >= 15 строк.
- Каждый ответ скопировать двумя способами: выделение+Ctrl+C и кнопка Copy.
- Сырые копии сохранять без обработки.
- Каждый сырой файл прогнать через check_markers.py --scan.
