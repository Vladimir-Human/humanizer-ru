# Артефакты Mistral Le Chat: протокол проверки

## Что уже известно из открытых источников (проверено 2026-07-13)

- Веб-поиск Le Chat даёт ответы с цитатами; в библиотеках (Libraries) — нумерованные сноски
  и кнопка Sources (docs.mistral.ai/vibe/work/libraries).
- В API цитаты передаются структурно (docs.mistral.ai/studio-api/conversations/citations) —
  служебных текстовых маркеров в стиле oaicite в документации не описано.
- Публично задокументированных уникальных строк-артефактов вставки (аналогов
  `?utm_source=chatgpt.com`) для Le Chat на момент исследования НЕ НАЙДЕНО.

## Ручной тест (выполнить в браузере, 15–20 минут)

1. В chat.mistral.ai задать 3 вопроса с включённым веб-поиском и 3 без него (русский язык).
2. Каждый ответ скопировать двумя способами: Ctrl+C из выделения и кнопкой Copy.
3. Вставить в файл и прогнать: python3 - <<'PY'\nimport sys;d=open('sample.txt','rb').read().decode('utf-8')\nfor ch in sorted(set(d)):\n    if ord(ch)>0x2000 or (0xE000<=ord(ch)<0xF900):\n        print(hex(ord(ch)), repr(ch))\nPY
4. Искать: скрытые символы PUA (U+E000–F8FF), utm/referrer-параметры в ссылках, служебные
   формы сносок, остатки JSON/тегов вокруг цитат.
5. Повторить для ответа с цитатами из загруженного документа (Libraries).
